# Lilith 臉部表情動點位置圖 (v2 — 擴充版)

## 座標系統說明
- 每個點都有一個「中性/靜止位置」(Neutral Position)作為基準點(0,0)
- 情緒觸發時,點位會向 **上(U)/下(D)/左(L)/右(R)** 四個方向移動(或組合,例如 U+L)
- 「左/右」定義:以角色本人視角為準(畫面右手邊 = 角色的左邊)
- **靜態參考點 (Reference Points)**:唔會因情緒而郁,只用嚟做頭部角度/縮放校正基準(參考業界 mocap 做法,例如耳朵、太陽穴)

## 強度量表 (Intensity Scale) — 核心標準

呢個量表決定每個點喺每個方向郁得幾盡,係成套系統嘅核心刻度:

| 數值 | 定義 | 適用對象 |
|---|---|---|
| **0** | 中性/靜止 | 所有角色的基準狀態 |
| **1** | 人類生理極限 | 寫實人類角色(如 Lilith)、寫實數位人、需要「可信」表情的虛擬主播 |
| **>1** | 超越人類極限 | 卡通角色(Yuna/Duffy/Mochi/Leo)、動畫誇張表現、機械人(硬體結構容許更大幅度郁動)、風格化角色 |

**標記方式範例**:每個點的每個方向都用「方向 + 數值」表示,例如:
- `EB-L3: U 0.6` → 左眉峰向上郁到人類極限嘅 60%(輕微挑眉)
- `EB-L3: U 1.0` → 郁到人類生理極限(最大幅度挑眉)
- `EB-L3: U 1.8` → 超出人類極限 80%(卡通/機械人誇張挑眉,人類做唔到)
- `MO-L: U 0` → 呢個點喺呢個情緒中冇郁(維持中性)

**用途**:
1. 同一套情緒規則(例如「開心」嘅方向邏輯)可以套用喺寫實角色(數值封頂喺 1)同卡通/機械人角色(數值可以去到 1.5-2+),唔使重新設計兩套系統——只需要調整「倍率」
2. 呢個亦係你產品嘅一個賣點:**同一套 Expression DNA,輸出時可選「寫實模式(≤1)」或「誇張模式(>1)」**,適合唔同客戶(數位人公司 vs 遊戲/動畫公司 vs 機械人公司)

### I. 瞳孔/眼球方向 (Eye Gaze) — 2 點 【新增】
呢類唔係皮膚/肌肉點位,而係眼球轉動方向——決定「望去邊度」,同眼瞼開合(EY-UP/EY-LOW)係獨立嘅兩個系統,要同時使用先夠完整。

| ID | 點位名稱 | 位置描述 |
|---|---|---|
| PL-L | 左眼瞳孔方向 | 左眼球中心朝向(相對正視前方的偏移) |
| PL-R | 右眼瞳孔方向 | 右眼球中心朝向(通常同 PL-L 同步移動,即「共軛凝視」) |

**強度量表喺呢類點位嘅特殊意義**:
- 0 = 直視前方(眼神接觸鏡頭/對話對象)
- 1 = 人類眼球喺唔郁頭情況下嘅舒適轉動極限(約 45°),超過呢個範圍人類會自然轉埋個頭
- \>1 = 唔適用於寫實人類角色(眼球結構唔容許),但機械人若果個「眼」係鏡頭/螢幕結構,可以有更大轉動範圍,故保留呢個彈性

**使用原則**:PL-L 同 PL-R 通常同方向同步移動(雙眼一齊望向同一點);如果兩者方向唔同,代表鬥雞眼/對焦異常,除非特別設計(例如恍神、機械人故障效果),否則要避免。
