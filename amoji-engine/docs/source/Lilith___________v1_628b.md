# 好萊塢/業界臉部動捕技術研究 —— 對 Lilith 系統嘅啟示

## 1. Weta FX(Avatar、猿人爭霸戰、魔戒)—— FACETS 系統
Weta 開發嘅 FACETS(奧斯卡科技獎得獎系統)做法:<cite index="25-1">用演員頭戴式雙鏡頭(stereo HMC)做高精度臉部追蹤,再由一個「solver」將追蹤到嘅微細點位數據,轉換做一組驅動角色嘅 blendshape(變形目標)數值。</cite>

**做法核心**:唔係直接郁動點位去變形個模型,而係「點位數據 → 解算 → blendshape 權重 → 驅動模型」,中間多一層轉換。

**對你嘅啟示**:你而家嘅系統(情緒值 → 57 點位值)已經係呢個邏輯嘅簡化版——你哋差嗰層係將「點位值」再轉做「實際模型嘅變形驅動值(blendshape)」。呢層轉換未來要接第三方 3D 模型/機械人嗰陣一定會用到。

## 2. ⚠️ 重要警號:Weta 對 FACS 嘅批評(Avatar 2 訪談)
呢個發現直接關係到你成套系統嘅理論基礎——你之前嘅點位表本質上係一種 FACS(Facial Action Coding System)嘅應用,但 Weta 嘅視覺總監 Joe Letteri 明確指出:

<cite index="22-1">FACS 雖然俾業界帶嚟一定程度嘅標準化,但佢原本係由心理學角度設計,用嚟捕捉「靜態、可分辨」嘅表情快照,並唔係為咗基於時間軸嘅動畫、更加唔係為咗對嘴形/講嘢而設計。</cite>實際應用上,<cite index="22-1">一套完整、可信嘅 FACS 動畫木偶(rig)可能需要多達 900 個 FACS 形狀,先可以令動畫師做到有說服力嘅表演——FACS 唔係「錯」,但佢從來唔係為咗「隨時間變化嘅臉部動畫」而設計。</cite>Weta 嘅結論係:<cite index="22-1">「我哋需要一套俾藝術家可以直接控制臉部行為嘅系統」。</cite>

**對你嘅啟示——呢個好關鍵**:
- 你依家做嘅靜態情緒表(開心/憤怒/驚訝⋯逐個填點位)本質上就係 FACS 快照式做法——呢個階段(定義「這個情緒長怎樣」)冇問題,亦係必要嘅基礎工作
- 但如果目標係「一套完整、有說服力嘅表演系統」,下一步唔應該淨係擴充更多靜態情緒快照,而係要諗**點樣喺情緒之間平滑過渡、點樣配合講嘢嘅嘴形(lip-sync)同時疊加情緒**——呢個先係好萊塢級系統肯做到但業界好多 AI 情緒公司做唔到嘅嘢
- 你之前設計嘅「Layer 3(時間/真實度層)」、微表情洩漏疊加,方向啱——因為呢啲正正係「時間軸上嘅行為」,而唔係靜態快照,呼應緊 Weta 講嘅缺口

## 3. 機會:ARKit 52 Blendshapes ——業界已有嘅事實標準
呢個發現對你嘅商業策略非常重要。<cite index="29-1">Apple ARKit 嘅 52 個臉部 blendshape 係一套預先定義好嘅表情集合,原理源自 FACS,而家已經廣泛用喺 AI 動作捕捉方案入面。</cite><cite index="29-1">每個 blendshape 用 0.0 到 1.0 嘅數值控制頂點移動幅度——中性狀態係 0.0,完整表情係 1.0。</cite>呢套標準<cite index="31-1">已經喺專業製作同「平價」方案兩邊都被廣泛採用,工作流程非常直接:捕捉數據 即時解算做 52 個標準形狀嘅權重,然後隨便邊套工具都食到呢組數據。</cite>

**呢個對你嚟講,係機會多過威脅**:
1. **你嘅「0-1(+)強度量表」概念,同 ARKit 嘅 0.0-1.0 blendshape 數值系統本質一致**——即係話你依家已經直覺咁設計緊一套同業界標準相容嘅邏輯,唔使推倒重來
2. **ARKit 52 已經係遊戲引擎、VTuber、VR 裝置嘅事實通用接口**——你套系統與其同佢競爭做「新標準」,不如將 ARKit 52 blendshapes 做「輸出兼容層」,你哋自己嘅 57 點/情緒引擎負責「輸入端嘅智能」(即係點樣由一個情緒詞彙,配合心理學規則,生成一組有真實感、有微表情、有不對稱嘅 blendshape 數值),呢個先係你哋嘅核心價值,而唔係重新發明一套點位系統要人哋學
3. **策略調整建議**:你套系統可以定位做「ARKit-compatible 嘅情緒智能層」——輸入係情緒語意(你嘅數值組 A),輸出可以映射做 ARKit 52 blendshapes 標準格式,咁樣任何已經支援 ARKit 嘅引擎/avatar(Ready Player Me、VRM 模型、Unity/Unreal 專案)都可以即插即用,大大降低客戶接入成本——呢個先係你最初講「所有 AI 都可以攞去用」嘅實際做法

## 4. 次要技術參考
- **雙鏡頭立體捕捉**:<cite index="19-1">用兩個鏡頭而唔係一個,可以生成更精準嘅 3D 網格,對於嘴唇突出/收窄呢類細節動作(例如噘嘴)特別重要,單鏡頭好多時要靠「估」。</cite>對你嚟講:如果將來想做真人示範片段生成表情數據,雙鏡頭/多角度參考可以提升精度
- **混合捕捉來源**:<cite index="22-1">Avatar 2 裡面,好多水底場景嘅演員表演捕捉,實際上係將陸上補拍嘅表情數據,同水中主要嘅表演捕捉數據混合出嚟。</cite>對你嚟講:呢個證明「分開捕捉、後製混合」係業界認可嘅正常做法,你唔需要一次過喺理想條件捕捉晒所有數據
