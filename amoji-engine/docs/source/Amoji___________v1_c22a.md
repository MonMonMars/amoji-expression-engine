# Amoji —— 盈利計劃逐項優劣對比表

將盈利流程與計劃文件入面嘅四條收入來源,加埋Higgsfield類新客戶,逐一列出
優劣勢,方便一眼睇晒點揀優先次序。

---

## 收入來源一:B2C —— App Store插件(而家主打)

| 優點 | 缺點 |
|---|---|
| 對話層可用Apple Foundation Models,200萬下載前近乎零成本 | 只限iOS/macOS,冇Android市場 |
| 表情層(Amoji引擎)本身零LLM成本 | Foundation Models仲喺beta,API可能仲會變 |
| 市場已驗證(Grok Companions、Character.AI證明需求存在) | 消費者App競爭激烈,獲客成本可能高 |
| 「LLM中立」定位有差異化空間 | 裝置端模型能力有限,唔啱複雜對話 |
| 冇需要企業銷售關係,可以獨立起步 | 200萬下載後成本結構會轉變,需要及早規劃遷移 |

---

## 收入來源二:B2B —— 機械人硬件商整合授權

| 優點 | 缺點 |
|---|---|
| 已有詳盡市場研究(UBTech/AheadForm/Realbotix),客戶輪廓清晰 | 決策鏈長,機械人公司採購週期通常以月/季計 |
| 客單價高(整合費+年度訂閱),單一客戶收入規模可觀 | 需要實際demo先有說服力,對初創嘅信任門檻高 |
| 呼應恐怖谷研究,有紮實技術差異化論述 | 客戶多數海外(中國大陸/英國/北美),接觸成本高 |
| 年度維護訂閱提供持續收入,唔止一次性 | 部分客戶(Realbotix)品牌背景複雜,盡職審查成本增加 |

---

## 收入來源三:B2B —— LLM/AI平台API訂閱

| 優點 | 缺點 |
|---|---|
| 訂閱制,收入可預測、可規模化 | Character.AI/Replika類公司已有自己內部團隊,未必願意外判 |
| 按用量計費,同客戶規模同步增長 | 客戶議價能力強(佢哋通常已經有龐大用戶基數) |
| 技術整合相對機械人授權簡單(純軟件對軟件) | 依賴客戶平台嘅API穩定性/政策 |

---

## 收入來源四(新增):B2B —— AI影片生成平台(Higgsfield類)

| 優點 | 缺點 |
|---|---|
| 客戶自己公開承認痛點(表情循環、細膩情緒唔準),銷售論述現成 | 呢個係全新市場,冇你哋自己嘅先例驗證 |
| 學術界已有Blendshape/AU控制信號嘅先例,技術方向唔使自己摸索 | 需要客戶技術團隊配合做adapter層,整合門檻視乎對方配合程度 |
| 按影片時長/幀數計費,收入同客戶用量同步 | Higgsfield呢類平台仍在快速演進,產品方向可能改變 |
| 唔使做影片生成本身,責任範圍清晰(止於控制信號) | 潛在客戶數量未知(除咗Higgsfield仲有邊幾間,需要進一步調研) |

---

## 已降級選項:B2C —— 動畫師工具

| 優點 | 缺點 |
|---|---|
| 技術上零邊際成本(工具性質,唔涉及持續LLM對話) | 市場證據唔足——目標買家(獨立動畫師)實際上多數受雇於公司,唔係自由買家 |
| 直接對口你自己嘅專業背景 | 如果轉型做B2B(賣俾動畫公司),銷售流程同機械人授權類似,決策鏈長 |

---

## 總覽建議優先次序(結合各項優劣)

```
第一優先:B2C App Store插件 —— 成本最低、市場已驗證、可獨立起步
第二優先:B2B AI影片生成平台 —— 銷售論述現成(客戶自己公開承認痛點),
  技術門檻適中,值得盡快接觸Higgsfield等公司做初步對話
第三優先:B2B機械人硬件商 —— 客單價最高,但需要實際demo同較長銷售週期
第四優先:B2B LLM平台 —— 客戶議價能力強,建議喺你哋有咗實績(App用戶
  數據/影片平台合作案例)之後先接觸,議價位置會更好
```
