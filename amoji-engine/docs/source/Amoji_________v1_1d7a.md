# Amoji —— 香港創業全流程:由零開始到開公司、搵客戶、搵投資者

⚠️ 免責聲明:我唔係律師/會計師/持牌顧問。以下係基於香港政府公開資料嘅事實整理,
方便你有個全局概念——實際註冊、稅務、法律文件,必須搵執業會計師/律師/公司秘書
處理,唔可以淨係跟呢份文件做。

---

## Phase 1:公司註冊(由零到有間公司)

### Step 1.1:揀公司結構
<cite index="10-1">私人有限公司(Private Limited Company)係香港超過90%企業採用嘅結構——
有限責任保障,亦都係銀行同投資者接受嘅標準格式。</cite>建議直接用呢個結構,唔使
考慮獨資(Sole Proprietorship,無限責任,可信度較低)。

### Step 1.2:法定要求(注冊前要準備)
<cite index="17-1">兩個強制要求:(1)香港註冊地址,用嚟接收政府同法律文件;(2)委任
一位通常居於香港嘅公司秘書。</cite>如果你自己已經喺香港,呢兩樣可以相對簡單安排
(自己屋企/辦公室做註冊地址,或者用秘書公司提供嘅虛擬地址服務)。

### Step 1.3:揀公司名
<cite index="9-1">公司名要符合公司註冊處指引、唔可以同現有公司重複。</cite><cite index="16-1">
中英文名一齊提交搜尋。</cite>

### Step 1.4:準備文件
```
- Form NNC1(法團成立表格,包含公司資料、董事、股東、股本詳情)
- 公司章程(Articles of Association)——可以用註冊處標準範本
- 全部董事/股東嘅身份證明文件
```

### Step 1.5:提交
<cite index="12-1">全程可以電子簽署或者郵寄,唔使親身去政府部門。</cite><cite index="16-1">
經 e-Registry 網上平台提交。</cite>

### Step 1.6:時間同費用
<cite index="14-1">公司註冊處通常5個工作天批出法團成立表格,商業登記證通常喺翌日發出。</cite>
<cite index="16-1">法團成立證明書通常1個工作天內發出。</cite><cite index="11-1">2026年
政府總費用:HK$3,895(法團成立費HK$1,545 + 商業登記證HK$2,350)。</cite>

### Step 1.7:注冊後即刻要做嘅嘢
<cite index="15-1">成立唔係終點——開始營運之前要準備好:法定登記冊(包括重要控制人
登記冊)、公司印章、會計同審計安排。</cite><cite index="16-1">仲要準備成員登記冊、
董事登記冊、押記登記冊,呢啲要存放喺註冊地址或者已通知嘅替代地址。</cite>

### Phase 1 Checklist
```
- 揀定公司結構(建議:私人有限公司)
- 安排註冊地址
- 委任公司秘書(香港居民或者持牌秘書公司)
- 中英文公司名做查冊
- 準備Form NNC1同公司章程
- 準備全部董事/股東身份證明文件
- 經e-Registry提交
- 收取法團成立證明書 + 商業登記證
- 準備法定登記冊(成員/董事/重要控制人/押記)
- 訂造公司印章
```

## Phase 2:銀行戶口同稅務登記

### Step 2.1:開公司銀行戶口
<cite index="11-1">香港銀行做嚴格KYC審查,開戶通常需要親身核實——部分FinTech方案
(例如Airwallex、Neat、Statrys)容許遙距開戶。</cite><cite index="13-1">如果傳統銀行
開戶緩慢,部分創辦人會用持牌虛擬銀行或者認可支付機構做過渡/補充方案——呢啲供應商
好多都提供完全遙距開戶服務。開戶必須用返已經合法註冊嘅公司名義,所以呢一步一定
跟喺公司註冊處同稅局申報之後,唔可以行先。</cite>

你嘅優勢:你已經喺香港生活,傳統銀行嘅親身核實對你嚟講相對容易,可以優先
考慮傳統銀行(信譽較高)。

### Step 2.2:稅務基礎概念
<cite index="14-1">2026年香港利得稅:首200萬港元應評稅利潤稅率8.25%,超過部分
16.5%——兩級制適用於合資格法團,每個集團只可以有一間實體用低稅率。</cite>

### Phase 2 Checklist
```
- 揀銀行(傳統銀行 vs Airwallex/Neat/Statrys等FinTech方案)
- 準備KYC文件(董事/股東身份、業務描述、預期交易流程)
- 完成銀行開戶(可能需要數日到數星期)
- 向稅務局做初步登記
```

## Phase 3:年度合規(注冊後持續要做嘅嘢)
<cite index="11-1">周年申報表(Form NAR1)必須喺公司成立周年日起42日內提交俾公司
註冊處,準時提交標準費用HK$105,逾期罰款由HK$870到HK$3,480不等。商業登記證
每年更新(2026年4月1日起HK$2,350)或者每三年續期一次。</cite>

### Phase 3 Checklist(每年循環)
```
- 周年申報表(NAR1)——成立周年後42日內
- 商業登記證續期
- 年度審計(必須搵執業會計師)
- 利得稅報稅表
```

## Phase 4:香港政府創業支援生態(搵資金/資源)

### Step 4.1:Cyberport vs HKSTP——揀邊個
<cite index="24-1">Cyberport專注數碼科技、創意產業、FinTech、電商、Web3;HKSTP專注
硬科技、生物科技、AI、機械人、醫療科技、物聯網,以更深厚嘅資金包同更長嘅培育期
見稱,同研究機構有強連結。一間實體唔可以同時受惠於兩個計劃——可以兩邊都申請,
但最終要揀一個先可以繼續。</cite>

對 Amoji 嘅意義:你哋嘅業務橫跨「軟件引擎」(似 Cyberport)同「機械人整合」
(似 HKSTP)——建議先評估你哋短期主打產品線(如果係 B2C App/動畫師工具,傾向
Cyberport;如果係機械人B2B授權,傾向HKSTP)。

### Step 4.2:具體資助金額
<cite index="18-1">Cyberport 培育計劃:最多HK$500,000資助。</cite><cite index="24-1">
培育期24個月。</cite><cite index="19-1">HKSTP 培育計劃:最多HK$1.29百萬資助,3年
綜合支援,幫助科技初創由早期技術開發到市場探索同業務發展。</cite><cite index="23-1">
HKSTP 分Incu-Tech(AI硬件/深科技)同Incu-App(AI軟件/應用)兩條track。</cite>

### Step 4.3:更大型嘅政府AI專項資金
<cite index="26-1">香港政府喺2024年財政預算案撥款30億港元(約3.83億美元)俾Cyberport,
做為三年期AI補貼計劃嘅一部分,協助本地大學、研究機構、企業使用AI超算中心嘅
運算能力。</cite><cite index="22-1">HK$100億創新基金專門針對AI、機械人、半導體;
HKSTP嘅Co-Acceleration Programme(2025年推出)專注生成式AI同可持續發展,提供
共同投資機會。</cite>

### Phase 4 Checklist
```
- 評估Cyberport vs HKSTP邊個更啱你哋主打產品線
- 準備申請材料(商業計劃書、技術描述、團隊履歷、財務預測——可以直接用返
  你哋已有嘅Amoji文件庫做基礎)
- 提交申請(Cyberport/HKSTP Incu-Tech或Incu-App)
- 準備盡職審查會議 + 評審小組簡報
- (如獲批)搬入指定辦公空間(視乎計劃要求)
```

## Phase 5:搵客戶——執行你哋已有嘅商業策略
呢部分你哋已經有完整文件,重點提醒:
```
- 短期:B2C AI動畫師工具首批用戶(你自己動畫背景做case study)
- 中期:App Store插件,主打「LLM中立」定位
- 中長期:接觸UBTech/AheadForm/Realbotix(已有詳細案例)
- 並行:接觸香港本地機械人/AI公司(可以透過Cyberport/HKSTP嘅網絡直接搭路)
```

香港特有優勢:<cite index="22-1">香港有40.3%嘅初創創辦人嚟自中國大陸,英國10.7%,
美國9.0%——呢個國際化網絡本身就係一個接觸客戶嘅渠道,Cyberport/HKSTP嘅活動同
demo day 通常聚集咗呢啲跨地區投資者/合作夥伴。</cite>

