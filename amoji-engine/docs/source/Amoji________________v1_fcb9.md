# Amoji 系統規格 —— Part V:微笑與大笑嘅類型研究

## 開場:你套系統一直將「開心」當做單一情緒——但研究話你知,笑分好多種

之前 v1-v11 嘅情緒表,「開心」只有一組固定嘅點位公式(強度 0-1)。呢份研究會證明,
**「開心」實際上係至少三種喺解剖學上唔同嘅微笑,加埋一種完全獨立嘅狀態(大笑)**,
各自有唔同嘅社交功能同身體動作簽名。

---

## Part 1:微笑唔止一種——三功能微笑模型(有精確 FACS 對照)

### 1.1 核心研究:Niedenthal 等人(2010)嘅「微笑模擬」模型
<cite index="73-1">Niedenthal 及同僚提出嘅微笑模擬模型,主張有三種喺物理形態同意義上都截然不同嘅
微笑類型:獎勵型微笑(reward smiles)、親和型微笑(affiliative smiles)、支配型微笑
(dominance smiles)。</cite>

### 1.2 三種微笑嘅精確 FACS 對照(可直接寫入你嘅 57 點位系統)
<cite index="74-1">獎勵型微笑屬於 Duchenne 微笑,特徵係對稱嘅嘴角上揚肌(AU12)、臉頰提升肌(AU6)、
嘴唇分開(AU25)及/或下顎下垂(AU26)。</cite><cite index="75-1">支配型微笑(AU5, 6, 9, 10, 12)、
獎勵型微笑(AU1, 2, 12, 13, 14)、親和型微笑(AU12, 14, 24),三者都包含 AU12(嘴角上揚),
但各自搭配唔同嘅「伴隨肌肉組」,分別服務緊唔同嘅適應性功能:協商階級地位、獎勵他人、
表示順從/示好。</cite>

**社交功能總結**:<cite index="76-1">獎勵型微笑傳達正面情緒同感官愉悅狀態(例如開心、逗趣),
可以同時獎勵發出者同接收者;親和型微笑傳達正面社交動機,用嚟建立同維持社交連結,發出者
意圖被視為友善、有禮貌;支配型微笑就用嚟建立同維持較高嘅社會地位,發出者意圖被視為優越。</cite>

| 微笑類型 | FACS 動作單元 | 對稱性 | 社交功能 | 對應你套點位系統 |
|---|---|---|---|---|
| **獎勵型(Reward)** | AU6+AU12+AU25/26(Duchenne) | 對稱 | 真誠愉悅,獎勵雙方 | CH-*(臉頰上揚)+ MO-L/R(對稱上揚)+ EY-LOW(下眼瞼提升)+ MO-CTR(唇分開) |
| **親和型(Affiliative)** | AU12+AU14+AU24(Non-Duchenne) | 較收斂 | 示好、非威脅、有禮貌 | MO-L/R(輕微上揚)+ 嘴唇輕壓(新參數,見下)+ **冇** CH-*/EY-LOW 明顯提升 |
| **支配型(Dominance)** | AU5+AU6+AU9+AU10+AU12 | 可不對稱 | 展示優越、地位 | EY-UP(眼瞼上揚)+ CH-*+ NS-*(鼻部輕微皺起)+ UL-*(上唇提升)+ MO-L/R |

**⚠️ 辨識難度差異**:<cite index="74-1">觀察者(包括人類判斷者同貝氏分類器)喺分辨親和型微笑
嗰陣,準確度低過分辨獎勵型同支配型——親和型微笑本身喺辨識度上就係比較模糊嘅。</cite>

### 1.3 Duchenne 微笑係「誠實訊號」——有實際行為數據支持
<cite index="80-1">研究發現,一個人自己嘅 Duchenne 微笑同佢自己嘅合作行為(用囚徒困境遊戲量度)
有正向關聯——證實咗過往嘅發現:Duchenne 微笑係合作意圖嘅誠實訊號,因為呢種微笑唔容易
刻意做出嚟。</cite>

### 1.4 Duchenne 微笑仲會「洩漏」人格特質
<cite index="75-1">研究將 Duchenne 微笑(有/冇)對五個人格特質做邏輯回歸,全部都有顯著結果:
攻擊性(負相關)、communion親和特質(正相關)、盡責性(正相關)、自大型自豪(負相關)、
可信賴度(正相關)。</cite>

**對你套系統嘅意義**:如果你想令一個人格檔案(例如「陪伴」人格)顯得特別可信賴/溫暖,
應該**優先使用獎勵型/Duchenne 微笑**,而唔係其他兩種;相反,「企業文件」人格如果要顯得
專業克制,親和型微笑(冇 CH-*/EY-LOW 明顯提升)先啱佢嘅定位。

### 1.5 不對稱微笑——都可以係真心,但眼動判讀方式唔同
<cite index="81-1">研究俾參與者睇三種微笑:對稱嘅 Duchenne、非 Duchenne、同不對稱微笑。結果
Duchenne 微笑被判斷為更開心;不對稱微笑都被判斷得比非 Duchenne 微笑開心。參與者判斷
不對稱微笑嗰陣,眼球喺左右臉之間跳動(saccade)嘅次數,比睇對稱微笑多——但佢哋仲係
較多將不對稱微笑判斷做「真心開心」。</cite>

## Part 2:大笑——一個完全獨立嘅狀態,唔止係「開心強度拉滿」

### 2.1 大笑本質上係高度社交嘅行為
<cite index="87-1">Provine 嘅研究發現笑聲透過親社會行為嚟建立聯繫,而且極具傳染性。</cite>
<cite index="88-1">笑聲係一個壓倒性嘅社交現象——一個人喺有其他人陪伴嗰陣,笑嘅機會比獨自一人高達
30倍。</cite>

### 2.2 笑聲會「感染」——甚至同笑話本身好唔好笑冇關
<cite index="86-1">研究確認笑聲本身足以引發更多笑聲/微笑——參與者聽到18秒嘅笑聲樣本,第一次
播放嗰陣大部分人都會笑或者微笑,但重複到第十次,好少人仲會笑,反而覺得個聲好煩——證實
笑聲本身可以觸發一個特定嘅聽覺特徵偵測機制。</cite>

**呢個對你套系統嘅意義**:如果你套系統要俾角色對「用戶嘅笑聲」做反應,建議**引入一個
「新鮮度」衰減機制**——連續播放/觸發同一種笑聲反應,傳染效果會遞減,唔可以每次都用
同一強度回應。

### 2.3 真笑 vs 擺拍笑——傳染力嘅曲線關係
<cite index="83-1">自發性笑聲(嚟自朋友)聽落最真實、最悅耳,跟住係陌生人嘅笑聲,再跟住係
擺拍嘅笑聲。但呢啲類型嘅笑聲喺「感染力」評分上冇分別——一個多項式迴歸發現,行為感染力
同真實度評分嘅關係係曲線嘅,喺高度唔真實(擺拍)同高度真實嘅笑聲兩端,感染力都係最高。</cite>

### 2.4 ⭐ 大笑嘅身體動作——嚟自動畫合成研究,可以直接攞嚟用
呢批研究特別有價值,因為佢哋本身就係為咗合成虛擬角色大笑動畫而做嘅:

**節奏性身體動作(RBM)**:<cite index="94-1">笑聲脈衝會產生肩膊同軀幹嘅明顯震動。呢啲動作
同呼吸階段有關,所以預期會有重複性同固定節奏。同呼吸相關嘅動作,可能會伴隨其他來源唔同
嘅身體動作,例如側向搖擺。</cite>

**⭐ 關鍵架構發現:頭部動作係主導,軀幹/肩膊係「衍生」動作**:<cite index="98-1">虛擬角色嘅
軀幹同肩膊動作,係由頭部動作合成出嚟嘅——具體做法係定義每個軀幹/肩膊動作嘅目標強度
(幅度),呢個目標強度由頭部動作決定,再用一個 PD 控制器嚟平滑咁驅動。</cite>

**呢個直接呼應你之前 accessoryMuscleActivation 嘅設計哲學**——唔使幫軀幹/肩膊動作獨立
寫一套參數,而係由頭部動作(dominant)推導出嚟(derived),減少手動調參,亦令個系統
更加統一。

### 2.5 唔同「笑」嘅類型,單憑身體動作(冇臉、冇聲)已經分得出
<cite index="92-1">研究發現觀察者單憑身體動作(用冇臉部細節嘅虛擬人示範),就可以分辨出
「捧腹大笑」「社交禮貌笑」「尷尬笑」「假笑」定「冇笑」。捧腹大笑同社交禮貌笑嘅分別在於:
脊椎彎曲嘅幅度、肩膊轉動嘅幅度、同手部動作嘅多少。</cite>而且<cite index="92-1">究竟邊啲身體
特徵可以判斷到笑緊,喺「坐低」同「企定」兩種姿態下係唔一樣嘅。</cite>

### 2.6 高階控制參數:強度 + 速度(同你套量表哲學一致)
<cite index="94-1">研究團隊用兩個標準化嘅高階變數——強度(intensity)同速度(velocity)——嚟
映射去合成節奏性身體動作所需嘅諧波參數,令系統可以用高階指令控制,例如「肩膊用某個強度
同速度震動」。</cite>

## Part 3:整合方案

### 3.1 「開心」情緒正式拆做四個子狀態

```
happy (家族) ─┬─ reward_smile    (獎勵型,Duchenne,預設/真心開心)
              ├─ affiliative_smile (親和型,示好/客氣,企業/服務場景用)
              ├─ dominance_smile  (支配型,自信/優越,某些人格場景用)
              └─ laughter         (大笑,獨立狀態,唔只係happy強度拉到盡)
                    ├─ 觸發:happy intensity > ~0.8 且 context 容許(人格檔案決定)
                    ├─ 身體動作:頭部動作主導 → 軀幹/肩膊震動幅度由頭部動作推導(PD控制器)
                    ├─ 呼吸:獨立於一般 accessoryMuscleActivation,大笑有自己嘅
                    │        脈衝式呼吸模式(唔係單純「快」,而係「一陣陣脈衝」)
                    └─ 傳染新鮮度:連續觸發同一強度,反應遞減(避免顯得罐頭式）
```

### 3.2 人格檔案 × 微笑類型嘅建議映射

| 人格 | 預設微笑類型 |
|---|---|
| 家居服務 | 獎勵型(溫暖真誠) |
| 企業文件 | 親和型(專業克制,絕少大笑) |
| 陪伴 | 獎勵型為主,容許大笑(關係深度嘅一部分) |
| 教育兒童 | 獎勵型(清晰、真誠,教學需要) |
| 醫療照護 | 親和型(溫和但克制,唔宜過度歡快) |
