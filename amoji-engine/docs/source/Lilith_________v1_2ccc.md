# Lilith 臉部表情動點位置圖 (v1)

## 座標系統說明

- 每個點都有一個「中性/靜止位置」(Neutral Position)作為基準點(0,0)
- 情緒觸發時,點位會向 **上(U)/下(D)/左(L)/右(R)** 四個方向移動(或組合,例如 U+L)
- 「左/右」定義:以角色本人視角為準(即畫面右手邊 = 角色的左邊),左右側點位分開標記,方便處理不對稱表情(例如單邊挑眉、冷笑)
- 移動幅度分級可用:小(1)/中(2)/大(3),留返下一步同情緒一齊定義
