## Part 1:收入來源(四條產品線,同開放協議策略整合)—— ⚠️ 已按市場修正重新排序

```
免費層(AEP協議 + 基礎引擎)—— 唔直接賺錢,用嚟建立採用率
  CC-BY 4.0協議文件 + 8基礎情緒/冇心情引擎/冇合規三機制
  目的:成為業界事實標準,吸引開發者/合作夥伴進入生態
              |
              v 轉化
⭐ 收入來源一(新主打):B2C —— App Store插件
  Freemium訂閱,主打「LLM中立」差異化定位
  ⭐ 對話層用Apple Foundation Models(裝置端+AFM Cloud,200萬下載前免費)
  ⭐ 表情/動作層用Amoji引擎(本身零LLM成本)
  現金成本:Apple Developer Program US$99/年起步,其餘近乎零邊際成本
  客戶:一般消費者
  市場驗證:真實存在(Grok Companions、Character.AI等已證明需求)

收入來源二:B2B —— 機械人硬件商整合授權
  一次性整合費 + 年度維護訂閱(整合費15-25%)
  客戶:UBTech/AheadForm/Realbotix類公司

收入來源三:B2B —— LLM/AI平台API訂閱
  按MAU/API調用量階梯收費,Starter→Growth→Enterprise
  客戶:Character.AI/Replika類公司,或者將來嘅類似平台

⭐ 收入來源四(新增):B2B —— AI影片生成平台表情控制信號授權
  按生成影片時長/幀數計費
  客戶:Higgsfield類AI影片/講嘢頭像生成平台
  市場驗證:Higgsfield自己公開承認「表情循環重複」「細膩情緒傳遞唔準確」
    「聲音語氣同塊面對唔上」呢三個痛點,同Amoji引擎嘅核心強項直接對口
  技術定位:唔做影片生成本身,做blendshape/AU控制信號供應商,
    對接影片平台自己嘅擴散/生成模型做conditioning輸入

⚠️ 已降級(市場證據不足):B2C 動畫師工具
  原假設「獨立動畫師付費買工具」市場驗證唔通過——大部分需要高階寫實表情
  嘅動畫師受雇於動畫公司,唔係自由工作者買家。保留可能性:重新定位做
  B2B(賣俾動畫公司本身),歸入收入來源二、三嘅範疇,唔再獨立做產品線
```

## Part 1.5:逐項優劣對比表(正式版,整合自對比表文件)

### 收入來源一:B2C —— App Store插件(而家主打)
| 優點 | 缺點 |
|---|---|
| 對話層可用Apple Foundation Models,200萬下載前近乎零成本 | 只限iOS/macOS,冇Android市場 |
| 表情層(Amoji引擎)本身零LLM成本 | Foundation Models仲喺beta,API可能仲會變 |
| 市場已驗證(Grok Companions、Character.AI證明需求存在) | 消費者App競爭激烈,獲客成本可能高 |
| 「LLM中立」定位有差異化空間 | 裝置端模型能力有限,唔啱複雜對話 |
| 冇需要企業銷售關係,可以獨立起步 | 200萬下載後成本結構會轉變,需要及早規劃遷移 |

### 收入來源二:B2B —— 機械人硬件商整合授權
| 優點 | 缺點 |
|---|---|
| 已有詳盡市場研究(UBTech/AheadForm/Realbotix),客戶輪廓清晰 | 決策鏈長,採購週期通常以月/季計 |
| 客單價高(整合費+年度訂閱) | 需要實際demo先有說服力 |
| 呼應恐怖谷研究,有紮實技術差異化論述 | 客戶多數海外,接觸成本高 |
| 年度維護訂閱提供持續收入 | 部分客戶品牌背景複雜,盡職審查成本增加 |

### 收入來源三:B2B —— LLM/AI平台API訂閱
| 優點 | 缺點 |
|---|---|
| 訂閱制,收入可預測、可規模化 | 客戶已有自己內部團隊,未必願意外判 |
| 按用量計費,同客戶規模同步增長 | 客戶議價能力強 |
| 技術整合相對簡單(純軟件對軟件) | 依賴客戶平台嘅API穩定性/政策 |

### 收入來源四:B2B —— AI Video Actor Engine(影片生成平台,Higgsfield/D-ID/HeyGen/Synthesia類)
| 優點 | 缺點 |
|---|---|
| 客戶自己公開承認痛點(表情循環、細膩情緒唔準),銷售論述現成 | 全新市場,冇你哋自己嘅先例驗證 |
| 學術界已有Blendshape/AU控制信號先例,技術方向唔使自己摸索 | 需要客戶技術團隊配合整合 |
| 按影片時長/幀數計費 | 市場仍在快速演進,產品方向可能改變 |
| 責任範圍清晰(止於控制信號輸出) | D-ID/HeyGen/Synthesia規模不一,需逐一評估接觸優先次序 |

### 已降級:B2C —— 動畫師工具
| 優點 | 缺點 |
|---|---|
| 技術上零邊際成本 | 市場證據唔足——目標買家多數受雇於公司,唔係自由買家 |
| 直接對口專業背景 | 如轉型B2B,銷售流程類似機械人授權,決策鏈長 |

### 總覽優先次序
```
第一優先:B2C App Store插件 —— 成本最低、市場已驗證、可獨立起步
第二優先:B2B AI Video Actor Engine —— 銷售論述現成,技術門檻適中
第三優先:B2B機械人硬件商 —— 客單價最高,但銷售週期長
第四優先:B2B LLM平台 —— 建議有咗實績先接觸,議價位置更好
```

## Part 2:優先次序同時間表(整合返所有文件嘅建議)

| 階段 | 時間 | 主要工作 | 對應收入 |
|---|---|---|---|
| 0. 公司/合規基礎 | 現在-2個月 | 香港公司註冊、Cyberport/HKSTP申請(如適用) | 冇收入,靠政府資助或自資 |
| 1. 核心引擎開發 | 2-6個月 | Phase 0-6(合規骨架→人格系統) | 冇收入 |
| 2. AEP協議發佈 | 6個月左右 | 公開CC-BY 4.0協議文件,開始建立生態 | 冇直接收入,但建立市場話語權 |
| 3. B2C App MVP | 6-9個月 | App Store插件,接駁Apple Foundation Models,首批用戶 | 開始有訂閱收入(收入來源一) |
| 4. B2C規模化 | 9-14個月 | 用戶增長,留意200萬下載嘅免費層上限 | 訂閱收入持續增長 |
| 5. B2B早期合作 | 12個月+ | 接觸UBTech/AheadForm/Realbotix、LLM平台、AI影片生成平台(Higgsfield類) | 大額整合費/授權開始出現(收入來源二、三、四) |
| 6. 大陸市場拓展(視情況) | 視前海資格確認結果 | 前海實體(如適用) | 稅務優化(企業稅15%) |

核心邏輯:短期(0-9個月)靠政府資助維持營運(而唔係營收),中期(9-14個月)
靠B2C訂閱開始有小額現金流,長期(12個月+)先至由B2B授權帶嚟真正有意義嘅
收入規模——呢個時間表同「先做決策鏈短嘅客戶,累積案例先再做大客戶」邏輯
完全一致。

## Part 3:成本結構(邊啲位使錢)

```
固定成本:
  - 公司年度合規(周年申報、商業登記證、審計)—— 每年約HK$1-2萬
  - 註冊地址/公司秘書 —— 每年數千至萬多蚊
  - (如喺前海設實體)前海辦公室租金 —— 有50%補貼,實際負擔減半

開發成本:
  - 你自己嘅時間投入(最大嘅「隱藏成本」)
  - 如需外聘開發者:視乎Phase 0-20嘅實際人力需求
  - 3D/渲染技術棧:Three.js免費起步,Unity視乎規模有授權費

法務/IP成本:
  - 商標註冊(Amoji)—— 相對低成本
  - 臨時專利申請 —— US$65(DIY)至US$5,000(律師)
  - IP審計(融資前建議做)—— 對估值提升15-20%,值得投資

行銷/商業發展成本:
  - Cyberport/HKSTP申請本身唔收費,但準備材料需要時間投入
  - B2B客戶開發:主要係你自己嘅時間/差旅(如需親身接觸UBTech等公司)
```

資金來源優先次序:
```
1. Cyberport(最多HK$50萬)或 HKSTP(最多HK$129萬)政府資助 —— 冇股權稀釋
2. 前海企業補貼(場地租金50%、如適用嘅其他補貼)—— 冇股權稀釋
3. B2C早期訂閱收入 —— 冇股權稀釋,但規模有限
4. (後期)天使/種子輪融資 —— 有股權稀釋,但呢個時候你哋已經有IP保護、
   初步產品、初步收入,議價能力遠好過而家
```

## Part 6:一頁總結——盈利邏輯

```
1. 免費開放協議(AEP)—— 建立業界標準地位,零收入但建立話語權
2. 政府資助(Cyberport/HKSTP/前海)—— 早期零股權稀釋資金,支撐開發期
3. B2C訂閱(動畫師工具+App)—— 第一批真實收入,驗證產品市場契合度
4. B2B授權(LLM平台+機械人硬件商)—— 真正規模化嘅收入來源,你哋IP/合規
   優勢喺呢層先完全體現
5. IP保護(商標+選擇性專利+商業機密)—— 保護第3、4步嘅收入唔被輕易複製
6. 稅務優化(香港+前海如適用)—— 提升淨利潤率,唔係新收入,但直接影響
   最終盈利
```
