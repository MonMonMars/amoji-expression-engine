你指出呢個做法會「重複」——即係口型同情緒兩組數值同時爭住去改同一個參數,冇一個真正「話事」。

## Part 1:臉部表情肌肉解剖學

### 1.1 三大肌肉分區(對應你套點位系統)

**眼眶肌群(Orbital Group)**
- **眼輪匝肌(Orbicularis Oculi)**:<cite index="222-1">環繞眼眶嘅肌肉,分瞼板部、淚囊部、眶部三部分——瞼板部負責溫和閉眼,眶部負責用力閉緊眼睛。</cite>對應你嘅 EY-*-UP/LOW 點位。
- **皺眉肌(Corrugator Supercilii)**:<cite index="222-1">位於眼輪匝肌後方嘅細小肌肉,負責將雙眉拉埋一齊,喺鼻樑產生垂直皺紋(皺眉嘅動作)。</cite>對應 EB-L1/R1(眉頭)。
- **額肌(Frontalis)**:<cite index="73-1">負責整體提起眉毛。</cite>對應 EB-*(全眉)同 FH-*(額頭)。

**鼻肌群(Nasal Group)**
- **鼻肌(Nasalis)、降眉間肌(Procerus)**:負責鼻部皺起(厭惡表情嘅關鍵肌肉)。對應 NS-*。

**口部肌群(Oral Group)**——呢個最關鍵,直接影響口型/情緒衝突問題:
- **口輪匝肌(Orbicularis Oris)**:<cite index="73-1">起源於上頜骨同下頜骨,插入嘴部周圍嘅皮膚同肌肉,負責閉合嘴唇(嘟嘴、前突)。</cite>對應 UL-*/LL-*/MO-CTR。
- **顴大肌(Zygomaticus Major)**:<cite index="73-1">起源於顴骨,插入嘴角嘅皮膚同肌肉,負責提起嘴角(微笑動作)。</cite>對應 MO-L/MO-R——**呢條肌肉正正係口型同情緒嘅「爭議地帶」**,下面詳述。
- **提上唇肌(Levator Labii Superioris)**:負責提起上唇(厭惡表情用)。對應 UL-CTR。
- **降口角肌(Depressor Anguli Oris)**:負責拉低嘴角(傷心/不滿表情用)。對應 MO-L/MO-R 嘅反方向。
- **笑肌(Risorius)**:負責將嘴角橫向拉伸(恐懼表情嗰種「橫向繃緊」正正係呢條肌肉)。對應之前恐懼情緒表入面嘅 mouthWidth 橫向拉伸邏輯——而家有咗解剖學根據。
- **頦肌(Mentalis)**:負責下巴/下唇嘅收縮突起(傷心嗰種「顫抖苦臉」)。對應 JW-CTR。

### 1.2 ⭐ 最關鍵嘅解剖學發現:下顎張開唔屬於「表情肌肉」

呢個係解決你問題嘅核心根據。研究資料清楚將「表情肌肉」(facial expression muscles,由面神經支配,
控制皮膚同軟組織)同「咀嚼肌肉」(mastication muscles,負責下顎骨郁動)分開處理:<cite index="73-1">
咬肌(Masseter)嘅作用係提升下頜骨(即係閉合口腔)——呢條肌肉屬於「作用於下顎」嘅分類,同顴大肌、
眼輪匝肌呢啲純表情肌肉唔同類。</cite>

**呢個解剖學事實直接解釋咗點解 JALI 模型會將口型拆做兩個獨立系統**:<cite index="85-1">JALI 模型指出,
講嘢有兩種模式——過度發音(hyper-articulate)嗰陣主要靠嘴唇肌肉郁動、下顎幾乎唔郁;含糊發音
(hypo-articulate)嗰陣就主要靠下顎/舌頭郁動、嘴唇幾乎唔使郁。日常對話係兩者按唔同比例混合。
佢哋將呢個拆做一個 2D 嘅「口型場」(Jaw × Lip 兩個獨立維度)。</cite>

**對你套系統嘅意義**:你之前嘅單一 `mouthOpen` 參數,其實混淆咗兩件解剖學上完全獨立嘅嘢:
- **下顎開合**(骨骼郁動,由咀嚼肌群控制)——呢個係口型嘅「音量/開口幅度」根本,情緒完全唔應該碰呢個系統
- **嘴唇形狀**(口輪匝肌、顴大肌等表情肌肉控制)——呢個先係情緒同口型真正「共用」嘅肌肉群

## Part 2:「爭議地帶」——邊啲肌肉係情緒同口型必然衝突嘅?

顴大肌(控制 MO-L/MO-R 嘴角)呢條肌肉,同時被兩個系統需要:
- **口型系統**需要佢嚟形成 E、AI 呢類口型嘅嘴角形狀
- **情緒系統**需要佢嚟表達開心(上揚)/傷心(下垂)

呢個先係真正嘅解剖學衝突。相反,**眉毛(額肌/皺眉肌)、眼睛(眼輪匝肌)、臉頰上部、鼻部**呢啲肌肉,
同口型系統完全冇解剖學重疊——呢啲區域,情緒可以 100% 話事,唔使同口型「爭」。

**呢個解剖學事實,先係你之前 ExpressionBot 文件講嘅「上下臉分離」規則嘅真正根據**——唔係一個
憑經驗定嘅設計選擇,而係**兩組肌肉本身就受唔同神經/骨骼系統控制**。

## Part 3:修正版——「覆蓋」架構(取代之前嘅相加混合)

### 3.1 核心原則:鎖定(Lock)vs 開放(Open),唔再係「相加」

每個口型對每一個嘴部參數,而家分做三種狀態,唔再係單一個連續權重:

| 狀態 | 意義 |
|---|---|
| **LOCKED(鎖定)** | 呢個參數由口型 100% 話事,情緒完全唔可以修改——因為呢個參數對於「聽得清楚」係必須嘅(例如 MBP 一定要完全閉合) |
| **CLAMPED(限幅)** | 情緒可以修改,但限制喺一個細範圍之內,唔可以突破口型嘅基本形狀 |
| **OPEN(開放)** | 情緒可以自由發揮,冇解剖學衝突(眉/眼/鼻/額) |

### 3.2 修正版口型表(jawOpen 拆返出嚟,對應 JALI)

| 口型 | jawOpen(下顎) | lipShape(唇形/mouthWidth) | corner(嘴角) |
|---|---|---|---|
| AI | OPEN(0.75) | CLAMPED ±0.1 | OPEN |
| E | CLAMPED(0.35±0.05) | CLAMPED ±0.15 | OPEN |
| O | CLAMPED(0.5±0.05) | **LOCKED**(0.75,唔可以畀情緒攞去做開心嘅闊嘴) | CLAMPED ±0.2 |
| U/WQ | CLAMPED(0.15±0.03) | **LOCKED**(0.6,嘟嘴形狀必須保持) | CLAMPED ±0.15 |
| FV | **LOCKED**(下唇貼牙,唔容許任何偏差) | LOCKED | CLAMPED ±0.1 |
| L | CLAMPED(0.3±0.05) | CLAMPED ±0.15 | OPEN |
| MBP | **LOCKED**(0,絕對閉合——呼應 JALI 講嘅「必須確保雙唇音閉合」) | LOCKED | CLAMPED ±0.15(嘴角仍然可以微調,閉住嘴都可以微笑) |
| CONS | CLAMPED(0.1±0.05) | OPEN | OPEN |
| REST | OPEN | OPEN | OPEN |

**呢個表直接解決咗 JALI 論文指出嘅弱點**:<cite index="85-1">Cohen-Massaro 主導模型嘅常見弱點,係未能確保雙唇音(/m b p/)嘅嘴唇閉合。</cite>因為你而家 MBP 嘅 jawOpen 同 lipShape 都係
**LOCKED**,情緒數值嘅 weight 幾大都好,個口一定閉到實——冇「相加」導致漏氣噉「開返少少」嘅情況。

### 3.3 對應嘅偽代碼(取代之前 v8 嘅加法公式)

```javascript
function resolveMouth(viseme, emotion, intensity) {
  const result = {};
  for (const param of ['jawOpen', 'lipShape', 'corner']) {
    const rule = VISEME_TABLE[viseme][param];
    if (rule.state === 'LOCKED') {
      result[param] = rule.value;              // 口型100%話事,情緒被完全忽略
    } else if (rule.state === 'CLAMPED') {
      const emotionDelta = emotion[param] * intensity;
      result[param] = clamp(rule.value + emotionDelta, rule.value - rule.range, rule.value + rule.range);
    } else { // OPEN
      result[param] = emotion[param] * intensity; // 情緒完全話事,口型唔提供數值
    }
  }
  return result;
}
```

**呢個同之前 v8 嘅分別**:v8 係 `viseme + weight×emotion`(兩者永遠都有貢獻,只係比例唔同);
而家係**狀態機**——LOCKED 嗰陣情緒嘅數值直接被忽略(唔會「加落去」,哪怕加極少都唔會),
先至係真正嘅「覆蓋」,唔會「重複」計算。

## Part 4:Layer 2 點位系統嘅解剖學正名(補充文件)

| 點位 | 對應肌肉 | 神經支配 |

| MO-L/R | 顴大肌(上揚)/ 降口角肌(下垂)/ 笑肌(橫拉) | 顏面神經(頰支/下頜緣支) |

神經系統**——呢個係「口型/情緒必須分軌處理」嘅最根本解剖學證據,唔止係工程上嘅方便做法。
