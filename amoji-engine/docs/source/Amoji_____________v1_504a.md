## Part 1:觸摸(Touch)—— 有精確神經科學數字

### 1.1 C 觸覺神經纖維(CT afferents)——愉悅觸摸嘅專屬感官通道
<cite index="113-1">研究運用微神經圖記錄法(microneurography),證實咗一組叫做 C 觸覺(CT)傳入神經纖維,
專門喺慢速觸摸、毛髮皮膚位置被激活。</cite>**具體速度數字**:<cite index="113-1">CT 纖維嘅激活程度,
同慢速撫摸(velocity 1 到 10 cm/s 之間)嘅愉悅度主觀評分,成線性關係。</cite>另一份研究確認:
<cite index="111-1">刷拭速度喺 1 到 10 cm/s 之間、接近皮膚溫度嘅觸摸,持續被評為比更慢或者更快嘅速度
更加愉悅。</cite>

**對你套系統嘅意義**:如果 Amoji 未來要做到有物理觸摸能力(機械人手臂/觸覺回饋裝置),
呢個「1-10 cm/s」係一個可以直接編碼嘅安慰性撫摸速度參數,唔係憑感覺定嘅。

### 1.2 深壓觸摸(擁抱、按摩)——另一種同樣有效嘅安慰觸摸
<cite index="107-1">深度壓力係一種常見於擁抱、依偎、按摩嗰陣嘅愉悅、鎮定觸摸類型。</cite>研究確認:
<cite index="112-1">深壓觸摸(類似擁抱同按摩)嘅愉悅機制,同慢速撫摸類似,都需要 A 類神經纖維嘅參與。</cite>

**⚠️ 重要備註**:機械人/AI 角色嘅物理觸摸功能涉及好多倫理、同意、安全考量,遠超出本文件
範圍——呢部分建議留返做未來擴充,而且必須有嚴謹嘅使用場景限制同用戶同意機制。

## Part 2:語氣同語速——推翻「安慰就係要慢慢講」呢個直覺

### 2.1 表面直覺:慢、柔、溫暖
<cite index="100-1">柔和嘅語氣聽落溫柔、平靜,通常用嚟表達同理心或者關懷——可以安撫聆聽者,特別喺敏感
對話入面。輕聲說話仲會傳達尊重同體貼。</cite>

### 2.2 ⭐ 但真實治療師/輔導員研究話你知:唔係「越慢越有同理心」
呢個發現嚟自實際心理治療對話錄音分析,比坊間泛泛而談嘅建議精確好多:<cite index="121-1">研究發現
「如果治療師講長句子但語速慢,或者講短句子但語速快,同理心水平就會偏低;相反,如果治療師
用穩定嘅語氣同音量對客戶講嘢,同理心水平就會偏高」。</cite>另一項研究補充:<cite index="121-1">
話語結尾嘅音節長度、靜默停頓、語速呢啲低層次嘅韻律時序線索,都會影響聆聽者對「治療師有
同理心」呢個高層次感知判斷。</cite>

**對你套系統嘅意義**:安慰模式唔應該粗暴噉將 `speechRate` 定為「一律減慢」,而係要令
**語速同句子長度匹配、保持穩定**(唔飄忽)——長句配合適中語速,短句都保持適中語速,
避免「長句慢吞吞」或者「短句急口令」呢兩種極端,兩者都會降低感知到嘅同理心。

### 2.3 情緒本身自然帶嚟嘅韻律變化(可以借嚟做「情緒鏡像」)
<cite index="120-1">當講者傷心嗰陣,語調音高同語速相對中性會降低;當講者開心嗰陣,語調音高同語速就會
提高。</cite>

**對你套系統嘅意義**:如果 Amoji 角色想同一個傷心嘅用戶「同頻」(呼應之前對話研究提到嘅
瞳孔同步機制),可以令自己嘅語調/語速輕微向用戶靠攏(mirroring),但要留意 2.2 嘅穩定性
原則,唔可以過度誇張咁減速。

### 2.4 溫暖語氣嘅表面特徵(業界應用共識,非嚴謹學術)
<cite index="99-1">語氣同音高,比起實際用嘅字眼,更加能夠提供穩定感同安慰。喺醫療同社會照護環境,
用支持、體諒嘅語氣,有助建立一個令人感受到被聆聽、被尊重嘅氛圍——關懷嘅語氣傳達緊同理心。</cite>

## Part 3:身體語言——一致性先係關鍵

### 3.1 開放姿態、專注聆聽動作
<cite index="101-1">維持開放姿態:企或者坐直,雙手放鬆垂放兩側,傳達開放同自信——呢個通常會令人感到
安慰。實踐主動聆聽:透過點頭、覆述、詢問澄清問題,展現專注同同理心。</cite>

### 3.2 ⭐ 不一致(Incongruence)會摧毀安慰效果——呢個先係最重要嘅原則
<cite index="104-1">一個回應可能措辭完美,但如果講嗰陣帶住諷刺語氣、雙臂交叉、或者反白眼,就會完全
失去同理心。我哋嘅臉部表情、手勢、姿態、聲音,會向對方發出安全或者威脅嘅訊號。</cite>更有
量化證據:<cite index="105-1">當語氣同身體語言唔匹配,聆聽者會相信身體語言多過語氣——講「我
好緊張你」但眼神望開或者交叉雙手,會傳遞矛盾訊息。有研究(University of Chicago)發現,
不一致嘅訊號會令人際情境嘅信任度下降 45%。</cite>

**對你套系統嘅意義**:呢個係全份文件最重要嘅單一原則——**安慰模式嘅成敗,取決於 Layer
1(表情)、Layer B(身體/語氣)、Layer V(語速/措辭)三者係咪完全一致,多過任何單一
Layer 做得幾「啱」**。如果劇本要求「安慰」情緒,但身體姿態嘅參數冇同步更新(例如仲係
交叉手臂嘅懷疑/防衛姿態),就算個口講緊安慰說話,都會被解讀做唔真誠。

### 3.3 有實證根據嘅「安慰訊息」特徵(Burleson 嘅人本安慰理論)
<cite index="106-1">有實證支持嘅安慰訊息核心特徵包括:(1) 對受困擾者投放主動關注;(2) 保持非批判
態度;(3) 回應聚焦喺對方嘅感受而唔係諗法;(4) 肯定同接納對方嘅個人經歷;(5) 俾返關於對方
感受嘅回饋。</cite>

## Part 4:整合方案——正式定義「安慰模式」(Comforting Mode)

```
Comforting Mode(situational overlay,可疊加喺任何人格之上)
├─ Layer 1(表情):concerned(關切,已於文件12定義)為主,避免快樂/興奮類表情
├─ Layer E(眼神):錨點鎖定對方(Dyadic-聆聽模式),避免游移分心
├─ Layer B(身體):
│   ├─ 開放姿態(chestExpansion 中性偏正,唔可以收縮防禦)
│   ├─ 輕微前傾(顯示專注,細節可掛落 headTiltVertical 輕微前傾)
│   └─ accessoryMuscleActivation 低(自己保持鎮定,唔可以被對方情緒感染到自己都繃緊)
├─ Layer G(手勢):
│   ├─ 唔可以有 Adaptor 類自我操縱動作(顯得心不在焉)
│   └─ 適量 Regulator(點頭確認,對應之前「聆聽者75%凝視+背channel」研究)
├─ Layer V(語速):速率同句子長度匹配、保持穩定,唔可以「一律減慢」
│   └─ 可輕微向用戶情緒鏡像(mirroring),但幅度克制
├─ 觸摸(如物理支援):1-10 cm/s 慢速撫摸,或深壓擁抱模擬
└─ ⭐ 一致性檢查(最高優先級):以上全部 Layer 輸出前,檢查有冇矛盾訊號
   (例如表情關切但身體仍然防禦收縮)——呢個檢查應該做成一個獨立嘅驗證步驟,
   唔止係逐個 Layer 各自輸出就算
```
