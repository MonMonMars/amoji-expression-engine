## 前海係咩、點解同你哋有關

前海深港現代服務業合作區,係深圳一個專門設計嚟促進深港經濟融合嘅特殊政策區域。
<cite index="31-1">前海合作區係深港合作嘅「橋頭堡」——前海深港青年夢工場已經孵化咗
460間香港創業團隊,成為「港人港企內地發展第一站」。</cite>

呢個直接對應你哋嘅情況:你已經住喺香港,又想接觸中國大陸市場(之前研究過嘅
UBTech、AheadForm都係大陸公司)——前海正正係為咗呢個路徑而設計嘅。

## 稅務優惠——兩個具體、剛剛延續嘅政策

### 1. 企業所得稅 15%(對比大陸標準稅率25%)
<cite index="29-1">設喺前海合作區嘅合資格企業,減按15%稅率征收企業所得稅——條件係
主營業務要符合《前海企業所得稅優惠產業目錄》,並且主營業務收入佔總收入60%以上,
仲要喺前海合作區內開展實質性運營。</cite>

剛剛發生嘅重要更新:<cite index="27-1">根據《財政部稅務總局關於延續實施前海
深港現代服務業合作區企業所得稅優惠政策的通知》(財稅〔2026〕3號),呢個稅收優惠
政策嘅執行期限延長至2027年12月31日。</cite>——即係話呢個優惠啱啱先確認會持續
多幾年,對你哋而家做決策嚟講係一個好時機。

### 2. 個人所得稅 15%(香港居民專屬)
<cite index="31-1">信息服務、科技服務、現代物流、商務服務、文化創意企業可享受
15%企業所得稅稅率,境外高端人才同緊缺人才可實行15%個人所得稅稅率。</cite>

具體資格條件:<cite index="28-1">享受呢個優惠嘅香港居民,必須同時符合:(1)
具有香港居民身份;(2)喺納稅年度內,喺前海合作區注冊嘅企業或機構任職、受雇並
實際工作,或者喺前海合作區提供獨立個人勞務/從事生產經營活動,並依法喺前海合作區
繳稅;(3)遵守法律法規,過去三年冇重大稅收違法失信行為。</cite>

對你嘅意義:呢個政策專門針對「香港居民」設計——你符合身份基礎資格,如果將來
Amoji喺前海設立實體、你自己喺嗰邊任職/收取酬勞,個人稅率可以由大陸標準累進稅率
(最高45%)大幅降到15%,呢個係一個相當實在嘅財務誘因。

### 3. 你哋嘅行業啱唔啱資格?
<cite index="31-1">信息服務、科技服務、現代物流、商務服務和文化創意企業可享受
呢個稅務優惠。</cite>

Amoji 極大機會符合「信息服務」或者「科技服務」呢兩個類別——表情引擎/AI軟件
授權,性質上屬於資訊科技服務業,同前海優惠目錄嘅適用範圍高度吻合(但實際界定
需要透過前海管理局嘅正式「產業界定」程序確認,唔係自己認為啱就得)。

## 對 Amoji 嘅實際建議路徑(框架性,唔係最終決定)

```
選項A(保守):純香港公司,唔即刻涉足前海
  優點:架構簡單,冇跨境稅務複雜度
  缺點:接觸大陸客戶(UBTech/AheadForm)可能需要額外跨境合約安排

選項B(進取):香港公司 + 前海子公司/分支
  優點:15%企業稅、15%個人稅(你自己)、前海AI公司先例(思謀科技)、
       前海夢工場專門孵化港人港企
  缺點:雙重架構嘅合規複雜度(兩地都要做年度合規)、前海嘅「產業界定」
       程序需要正式申請同審核,唔係自動符合資格

選項C(中間路線):先以香港公司同大陸客戶簽約/授權,觀察業務規模,
  等有實際大陸業務量先決定係咪值得喺前海設實體
```

我建議嘅思路(僅供參考):你哋而家仲喺概念驗證階段,建議先完成香港公司註冊同
Cyberport/HKSTP 培育,累積咗實際產品/初步客戶之後,先評估前海實體嘅必要性——
前海嘅稅務優惠喺你哋有實際大陸營收嗰陣先會顯著見效,現階段過早設立雙重架構
可能增加唔必要嘅合規負擔。
