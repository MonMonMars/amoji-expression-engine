# 人類臉部表情全清單 + 演員訓練研究 + 系統深化規格

## Part A:「所有人類臉部表情」嘅學術清單

一個好重要嘅澄清先:心理學研究入面,「有幾多種表情」呢條問題本身經歷過一次典範轉移。

### A.1 舊典範:六大基本情緒(你已經做晒)
開心、傷心、憤怒、驚訝、厭惡、恐懼——呢個係 Ekman 六十年代提出,長期被當做「全部」。

### A.2 新典範:複合情緒(Compound Emotions)—— 21 種基礎類別 + 中性
Ohio State University(Du, Tao & Martinez, 2014,發表喺 PNAS)嘅研究推翻咗「淨係六種」呢個假設:<cite index="38-1">過往研究主要集中喺六種基本臉部表情類別,但實際上人類經常使用嘅表情遠遠不止呢六種。</cite>研究團隊<cite index="39-1">定義咗 21 種唔同嘅情緒類別</cite>,方法係<cite index="43-1">分析 230 位受試者嘅 5,000 張表情圖像,並用 FACS 按參與者用到嘅臉部肌肉分類。</cite>

**完整 22 個類別清單**(中性 + 6 基本 + 15 複合):<cite index="46-1">happy(開心)、sad(傷心)、fearful(恐懼)、angry(憤怒)、surprised(驚訝)、disgusted(厭惡)、happily surprised(開心的驚訝)、happily disgusted(開心的厭惡)、sadly fearful(傷心的恐懼)、sadly angry(傷心的憤怒)、sadly surprised(傷心的驚訝)、sadly disgusted(傷心的厭惡)、fearfully angry(恐懼的憤怒)、fearfully surprised(恐懼的驚訝)、fearfully disgusted(恐懼的厭惡)、angrily surprised(憤怒的驚訝)、angrily disgusted(憤怒的厭惡)、disgustedly surprised(厭惡的驚訝)、hatred/憎恨、awed/敬畏</cite>,加埋 neutral(中性)同 appalled(震驚厭惡)。

**呢個發現嘅核心邏輯**(對你套系統極度重要):<cite index="36-1">FACS 分析顯示,呢 21 個類別嘅產生方式各有唔同,但同佢哋所屬嘅子類別一致——例如「開心的驚訝」呢個表情,結合咗喺「開心」同「驚訝」兩個表情入面分別觀察到嘅肌肉動作。</cite>換句話講:**複合情緒唔係將兩個表情嘅數值做平均(50/50 blend),而係從每個基礎情緒攞返佢最具代表性嘅特定肌肉區域,組合埋一齊**。具體例子:<cite index="48-1">「開心的驚訝」表情有 93% 嘅參與者用同一種方式表達:用返「驚訝」嘅大睜眼,加上「開心」嘅顴骨上揚。</cite>

**驗證咗跨文化一致性**:<cite index="44-1">喺一個高難度嘅辨識測試入面,參與者要從 21 個標籤入面認出表情,西方人同東亞人嘅表現喺統計上完全一致</cite>,證明呢啲複合表情唔係文化建構,而係有生物學根據。

**對你套系統嘅直接啟示**:你之前做嘅八個情緒(開心/憤怒/傷心/厭惡/驚訝/恐懼/思考/懷疑)全部係「單一」表情。呢個研究話你知,下一階段最有價值嘅擴充唔係加更多單一情緒,而係**將已有嘅情緒兩兩組合**——因為呢啲先係人類日常最常用、但現有 AI 系統幾乎冇覆蓋嘅表情(例如「開心的驚訝」=生日派對嗰刻;「傷心的憤怒」=覺得被辜負;「恐懼的厭惡」=見到令人反胃又驚嚇嘅嘢)。

## Part B:演員訓練研究 —— 演員點樣控制情緒同轉換

你講「機械人其實就係演員」呢個諗法,搵到一個直接、有科學根據嘅對應。

### B.1 Alba Emoting(阿爾巴情緒法)—— 最直接回答「轉換過程」嗰個技術
呢個係實驗心理學家 Susana Bloch 用超過 20 年研究出嚟,<cite index="57-1">專門為演員同表演教師而設,等佢哋唔使靠個人回憶或者其他間接方法都可以喺表演入面誘發同表達真實情緒。</cite>

**核心原理**:<cite index="55-1">六種基本情緒(以及情緒中性狀態)各自都有一套獨特、可辨識嘅身體反應模式,呢啲模式對全人類都係通用嘅。透過重現呢啲模式嘅三個部分——呼吸、姿勢、臉部表情——一個人可以喺唔靠回憶或者想像畫面嘅情況下,隨意誘發同表達真實、有機嘅情緒。</cite>

**六種基本情緒(注意同 Ekman 唔同,呢個版本嚟自生理心理學)**:<cite index="55-1">憤怒、溫柔、恐懼、情慾、悲傷、喜悅</cite>,加埋中性。

**每個模式嘅三個組件**:<cite index="55-1">(1) 呼吸模式,(2) 臉部表情,(3) 姿勢態度——三者共同運作,構成一個「效應器模式」(effector pattern),即係一個生物代碼,直接刺激細胞同器官,令身體整體進入呢個情緒狀態。</cite>

**⭐ 「Step-Out」—— 呢個直接回答你問嘅「轉換過程」**:<cite index="55-1">最重要嘅係第七個模式,叫「step-out」(跳出),一個人可以用呢個模式隨意離開任何情緒,返回心理生理學上嘅中性狀態。</cite>研究過程仲發現咗一個關鍵現象:<cite index="62-1">當演員練習呢啲模式嗰陣,誘發出嚟嘅情緒有時會喺練習完咗之後仍然殘留——所以佢哋專門開發咗呢套「step-out」技術,用特定嘅身體動作打斷情緒模式,等演員可以隨意結束一個情緒狀態,進入非情緒化狀態。</cite>具體做法一個範例:<cite index="59-1">雙腳與髖同寬企好,雙手喺身前扣埋,深吸氣同時將雙手舉過頭頂,然後吐氣同時側身、雙手放低(好似抱住一個大沙灘球咁),重複呢個呼吸加動作三次,再轉身彎腰壓向一邊腿、放鬆、還原,另一邊重複,最後輕拍臉部釋放殘餘緊張。</cite>

**方法學細節**(對你設計轉換動畫有實際參考價值):<cite index="56-1">實驗程序係:先教演員採用某個呼吸模式,但唔講呢個模式對應邊種情緒;然後加入姿勢部分;最後先加入臉部表情部分。</cite>即係話,**呼吸先於姿勢,姿勢先於臉部表情**——呢個時序同我哋之前發現嘅「先眼後口」原則(微表情研究)屬於同一類發現:真實情緒嘅顯現有固定嘅生理時序,唔係成套一齊彈出嚟。

### B.2 Andy Serkis(表演捕捉之父,Gollum、King Kong、Caesar)
Serkis 對「表演捕捉演員」呢個角色有幾個核心原則,直接回應緊你「機械人係咪都算演員」嘅問題:

**演戲就係演戲,冇分別**:<cite index="67-1">「無論你係著服裝定係用表演捕捉鏡頭去捕捉你嘅表演,之後角色先著衫或者加數碼化妝——呢樣嘢會影響到演戲嘅過程,但呢個過程本質上係一樣嘅:點樣建立一個角色嘅心理狀態、角色本身、同角色嘅情緒內容,點樣同其他演員同導演一齊演繹主題。呢啲嘢完全冇變過,呢個純粹就係演戲。」</cite>

**唔好誇張演繹,信任技術**:<cite index="64-1">「你唔使過度啞劇化咁演繹你想表達嘅情緒。相信呢套技術,佢好敏銳。你感受緊嘅一切都會傳遞出嚟,你唔使『扮鬼扮馬』。」</cite

**要有一個唔可以跌落嘅內在能量下限**:<cite index="64-1">「你要建立一種內在嘅生理能量,呢個能量有個底線你唔可以跌落去——你要比以往任何時候都更加活在當下嘅一刻。你唔可以就咁軟綿綿咁企喺度,除非你個角色本身就係一個軟綿綿企喺度嘅人。」</cite>

**你既係木偶,亦係操偶師**:<cite index="64-1">「你係驅動緊呢套技術——你既是木偶,亦是操偶師。」</cite>

**James Cameron 嘅補充**(Avatar 導演):<cite index="71-1">「演員做嘅唔係『動作』,而係『情緒』」——呢句說話喺 2009 年 Comicon 講嘅,強調表演捕捉嘅重點永遠係情緒真實度,唔係動作精度。</cite>

**對你套系統嘅直接啟示**:
1. **唔好將強度預設得太盡**——Serkis 明確講「唔使扮鬼扮馬」,真實嘅表演往往喺中低強度(你套量表嘅 0.3-0.6)已經夠傳神,一開始就用 0.9-1.0 反而會顯得假、顯得「用力做戲」
2. **內在能量下限**呢個概念可以轉化做你系統嘅一個新參數——一個角色喺中性狀態時,唔應該係「數值全部 0」嘅死寂狀態,而係有一個好輕微嘅底噪(呼吸、眨眼、微幅頭部擺動),對應「活在當下」呢個要求

## Part C:整合方案 —— 深化 Layer 3,加入「複合情緒引擎」同「Step-Out 轉換系統」

依家你套系統可以正式擴展做四個組件:

### C.1 複合情緒引擎(Compound Emotion Engine)
唔再淨係「一次揀一個情緒」,而係支援「兩個基礎情緒各自貢獻唔同臉部區域」:

```
複合情緒 = {
  primary:   { emotion: "happy",     dominant_regions: ["cheek","mouth","blush"] },
  secondary: { emotion: "surprised", dominant_regions: ["brow","eye"] }
}
```
例如「開心的驚訝」= 眉毛/眼部攞「驚訝」嘅數值,臉頰/嘴部攞「開心」嘅數值——呢個直接對應返 Martinez 研究入面「93% 人一致噉樣表達」嘅發現,唔係憑空up亂 combine。

**建議優先做嘅 6 組複合情緒**(揀最常用、最有戲劇性用途嘅):開心的驚訝、傷心的憤怒、恐懼的厭惡、恐懼的驚訝、憤怒的厭惡、傷心的恐懼。

### C.2 Step-Out 轉換系統
每個情緒新增一個「離場曲線」,唔再係「數值直接跳返 0」,而係模仿 Alba Emoting 嘅邏輯——**有固定嘅退場時序同動作特徵**(例如深呼吸感嘅胸腔/肩膀輕微下沉動畫、臉部肌肉逐步鬆弛而唔係瞬間歸零)。呢個對於「表情之間過渡」呢個 Weta 話 FACS 做唔到嘅缺口,係一個具體可實作嘅答案。

### C.3 呼吸先於姿勢、姿勢先於表情(組件先後時序)
未來如果套系統擴展到全身(唔止臉),入場時序建議跟返 Alba Emoting 驗證過嘅次序:**呼吸變化 → 姿勢/肩頸變化 → 臉部表情變化**,先會顯得由內而外、有機,唔會顯得「純粹換咗個表情貼圖」。

### C.4 「非零底噪」中性狀態
中性(intensity=0)唔應該係完全靜止——建議加一個永遠運行嘅微幅參數(呼吸起伏、眨眼、極輕微嘅頭部/眼神游移),對應 Serkis 講嘅「內在能量下限」,先唔會顯得死寂/機械。
