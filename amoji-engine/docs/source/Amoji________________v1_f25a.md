# Amoji 系統規格 —— Part S:對話 vs 演講/簡報嘅眼神、頭部、身體模式研究

## 核心框架:呢個唔係一套規則,係兩套完全不同嘅模式
你問嘅四個場景——同人對話、舞台演講、簡報、溝通——可以歸納做兩大類,各自有唔同嘅眼神
邏輯:**一對一對話(Dyadic)** vs **一對多演講(Presentation)**。呢兩者嘅眼神策略係相反嘅
邏輯,唔可以用同一套參數處理。

---

## Part 1:一對一對話(Dyadic Conversation)—— 有嚴謹學術研究

### 1.1 聆聽者 vs 講者,眼神比例完全唔同(經典發現)
<cite index="39-1">研究一致發現,喺兩人對話入面,人哋喺聆聽嗰陣望對方嘅時間,比自己講緊嘢嗰陣望對方嘅時間
更多。Kendon(1967, 1990)更精確噉描述咗呢個分別:聆聽者傾向維持長時間嘅凝視,中間夾雜住
短暫嘅移開視線;講者就會喺望向同望開對方之間交替,兩種狀態嘅持續時間大致相若。</cite>

**具體數字**:<cite index="41-1">聆聽者平均有 75% 嘅時間望住講者。</cite>跨語言/文化驗證:
<cite index="40-1">講者望向聆聽者嘅比例喺唔同語言都偏高(Tzeltal 語 65.7%、義大利語 79.9%、Yeli Dnye 語
79.9%),但聆聽者望向講者嘅比例相對較低(Tzeltal 42.3%、義大利語 63.3%、Yeli Dnye 67.3%)。</cite>

### 1.2 輪流發言嘅眼神訊號(Turn-Taking Cues)
<cite index="42-1">研究發現喺輪流轉換嗰刻,講者會用望住聆聽者嚟結束自己嘅發言回合,而聆聽者開始講嘢嗰陣,
眼神反而係移開嘅。</cite>更精細嘅時序:<cite index="40-1">講者應該喺回合尾段望向對方嘅頻率高過回合開始
嗰陣——因為回合開始嗰陣,講者需要專注去組織緊將要講嘅嘢;回合結束時,雙方應該有高度嘅互相
凝視,先方便將發言權交俾對方。</cite>

**對你套系統嘅意義**:「開口講嘢前眼神先移開」同「講完/準備讓出話語權嗰刻望返向對方」係
兩個可以直接編碼嘅明確訊號:
- `turn_start`:觸發輕微 gaze aversion(對應之前思考模式研究,連貫使用)
- `turn_end`:觸發 gaze lock 返去對話對象(anchor 鎖定)

### 1.3 長回合入面嘅「檢查式」凝視
<cite index="45-1">講者好可能會喺長篇發言入面嘅語句間停頓位,望向聆聽者——可能係想確認聆聽者仍然跟得上。
聆聽者通常會喺呢啲「語句間停頓凝視」嗰陣,做出表示理解嘅回應訊號(背channel)。</cite>

### 1.4 眼神交會嗰個「時刻」本身,先係關鍵訊號
2024年一項用瞳孔追蹤嘅新研究修正咗一個常見誤解:<cite index="46-1">眼神交會嗰一刻標誌住共同注意力
嘅高峰——而唔係一段持續鎖實嘅凝視期間嘅開始。</cite>而且發現咗一個優雅嘅生理同步現象:
<cite index="46-1">研究人員追蹤講者複述正面或負面回憶嗰陣嘅眼球動作,再追蹤聆聽者事後聽同一段故事嗰陣嘅眼球
動作,發現當故事去到情緒高峰位,聆聽者嘅瞳孔放大程度會同講者同步——呢個係雙方「同頻」嘅
指標。</cite>

**對你套系統嘅意義**:呢個對之前 Layer E 嘅瞳孔放大機制係一個重要補充——瞳孔同步唔止係
角色自己嘅情緒表達,仲可以做「回應對方情緒」嘅機制:如果角色扮演聆聽者角色,可以喺對話
對象(輸入端如果有情緒資料)講到情緒高峰嗰陣,同步調整自己嘅瞳孔放大幅度,模擬呢種「同頻」
訊號。

## Part 2:舞台演講/簡報(Presentation)—— 應用層級嘅共識技巧

⚠️ **重要區分**:呢部分嘅內容主要嚟自演講教練/傳播學教材嘅實務經驗總結,唔係好似 Part 1
咁有嚴謹嘅眼動追蹤學術研究支持。建議喺你套系統嘅文件入面清楚標明呢個信心水平嘅分別
(呼應之前 Easter Egg 文件嘅做法)。

### 2.1 「三角掃視法」(Triangle Technique)
<cite index="48-1">將觀眾分做三個區域(左、中、右),用鬆散嘅三角形模式喺呢幾個區域之間輪流轉移視線——呢個
會令你睇落好似同全場所有人講緊嘢,就算喺一個大房間都做到。</cite>

### 2.2 停留時間嘅共識:大約 3-5 秒
<cite index="48-1">對於每個人或者每個區域,建議停留視線 3 到 5 秒先轉去下一個目標——長到俾人感受到真實
連結,但短到唔會令人尷尬。眼睛應該平滑咁移動,而唔係亂咁跳嚟跳去,後者會令你顯得緊張。</cite>
另一個變體係:<cite index="54-1">「5-5-5 法則」——揀五個唔同嘅觀眾,每個凝視五秒,每五分鐘循環
一次,目的係減少緊張習慣、打破機械式掃視。</cite>

### 2.3 ⚠️ 有爭議嘅做法:「持續掃視」vs「完整思路連結」
唔係所有教練都同意「掃視」係最好做法:<cite index="56-1">有實戰教學者指出,持續嘅掃視反而會俾人感覺
緊張、迴避、甚至唔可信,好過持續掃視,佢哋建議「揀一個人,做真正嘅眼神連結,維持到你講完
一整個完整思路/句子先轉」。</cite>

**呢個對你套系統嘅意義**:呢兩種做法可能對應緊唔同嘅「人格模式」——大型演講/大房間可能
更加需要傳統嘅三角掃視(照顧到全場),但更加親密、想建立信任感嘅簡報場景(例如一對幾人嘅
會議簡報),可能「一人一完整思路」嘅做法更有效。建議做成兩個可選子模式,而唔係單一定案。

### 2.4 講者嘅三角形(身體移動同內容結構掛鈎)—— 呼應你之前 Layer W
<cite index="50-1">喺經典演講架構入面,舞台位置用嚟引導講者同觀眾經歷過渡:「講者三角」意味住講者由
開場位置開始,轉去第二個位置講第一點,再轉去第三個位置講第二點,然後返去原本位置做第三點
同結論——呢個移動技巧可以幫你記住每個要點,將演講拆做可管理嘅部分,你嘅移動會展現目的性、
強化可信度。</cite>

**對你套系統嘅意義**:呢個直接可以掛落 Layer W(步態)——**演講模式嘅移動唔係情緒驅動嘅
步態(開心/憤怒嗰種),而係「劇本結構驅動」嘅移動**,類似之前 Layer G 嘅 Emblem(LOCKED,
劇本指令覆�Alt情緒)概念:劇本可以標記「移到第二點位置」,觸發一個中性、目的性嘅移動,
唔理當時情緒強度值係咩,都應該保持沉穩、有目的感嘅步伐(唔應該用開心/憤怒嗰啲誇張步態
覆蓋咗演講嘅專業感)。

### 2.5 攝影機/視像場景嘅特殊規則
<cite index="48-1">虛擬簡報:要直視鏡頭本身,唔係螢幕上顯示緊嘅人臉——呢個好反直覺,但係喺視像
情境下模擬眼神接觸嘅唯一方法。</cite>呢個亦有量化研究支持:<cite index="53-1">研究發現視像會議入面,
會議主持人有 30% 嘅時間直視鏡頭,可以顯著提升參加者事後記得幾多內容。</cite>

**對你套系統嘅意義**:如果 Amoji 角色本身係俾人喺視像/App 入面對話(對應你之前 B2C App
Store 插件呢條產品線),Layer E 嘅錨點邏輯要特別設計「鏡頭模式」——錨點應該鎖定緊「虛擬
攝影機」位置,而唔係螢幕上顯示緊嘅使用者臉部影像位置,先符合呢個反直覺但已驗證嘅原則。

## Part 3:整合方案——Conversational Context Mode(掛喺 Layer E 之下)

```
Layer E · 眼球運動子系統(擴充)
└─ Conversational Context Mode(新增子模式選擇器)
    ├─ Dyadic Mode(一對一對話)
    │   ├─ 講緊嘢:錨點在「望向對方」/「望開」之間交替,兩者時間大致相等
    │   ├─ 聆緊嘢:錨點持續鎖定對方,約75%時間,中間夾雜短暫移開
    │   ├─ turn_start 觸發:短暫 gaze aversion(對應思考模式邏輯)
    │   ├─ turn_end 觸發:gaze lock 返去對方
    │   └─ 瞳孔同步:對話對象情緒高峰時,同步調整自己瞳孔放大幅度
    │
    └─ Presentation Mode(演講/簡報/多人)
        ├─ 多重錨點池(對應觀眾分區或者多個聆聽者)
        ├─ 掃視節奏:每個錨點停留 3-5 秒,平滑轉移(唔可以用微掃視嗰種跳動感)
        ├─ 避免偏愛:同一錨點唔可以太頻密重複揀選
        ├─ 子選項:「三角掃視」(大場合)vs「完整思路連結」(細場合/建立信任)
        ├─ 掛鈎 Layer W:身體位置轉換由劇本結構觸發(講者三角),覆蓋情緒驅動嘅步態
        └─ 鏡頭模式(視像場景):錨點固定去虛擬攝影機位置,唔係使用者臉部畫面位置
```
