# Lilith 臉部動點位置圖 v3——擴充版(在57點基礎上新增)

呢份文件喺文件3(57點專業版)基礎上,新增細節點位,涵蓋之前未覆蓋嘅區域(太陽穴、
耳朵、下頜輪廓、人中兩側、鼻樑上部)。新增點位延用返 v2 嘅座標系統同強度量表(0/1/>1),
唔重複解釋。

## 新增點位總表(共 18 點)
