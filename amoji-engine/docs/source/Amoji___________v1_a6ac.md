# Amoji —— 授權收入模式:費率與條款建議

⚠️ 免責聲明:我唔係律師,以下純粹係基於同業定價模式嘅框架性建議,實際條款
必須由律師審閱、實際費率必須因應市場測試調整。

---

## Part 1:授權模式選項(按客戶類型分流)

### 1.1 B2B #1——大型 LLM/AI 平台公司授權
建議模式:API 訂閱制(按調用量/月費階梯)
```
Starter層:  較低月費,涵蓋基礎8情緒+人格系統,適合小型/測試客戶
Growth層:   中等月費,加複合情緒引擎+心情引擎+眼球錨點系統
Enterprise層:客製報價,加合規三機制、全套Layer B/W/G、專屬人格開發
```
建議計費基礎:按「唯一活躍用戶數」(MAU)或者「API調用次數」,而唔係
一次性授權費——呢個做法令你哋嘅收入同客戶嘅實際使用規模掛鈎,亦都符合
「授權收入>服務收入」提升估值嘅原則。

### 1.2 B2B #2——機械人硬件商授權(UBTech/AheadForm/Realbotix類)
建議模式:一次性整合費 + 年度維護/更新訂閱
```
整合費:因應硬件複雜度議價(自由度越多,整合工作量越大,建議費用同呢個掛鈎)
年度訂閱:整合費嘅15-25%,涵蓋規則庫更新、新情緒/新原型擴充、合規更新
        (呼應各地監管持續演變,呢個訂閱本身有實際維護價值)
```
建議加入嘅條款:
- 客戶唔可以將 Amoji 輸出結果,回頭訓練/建構偵測用戶情緒嘅系統
- 客戶自行加裝嘅感知/偵測模組,必須喺自己文件明確標示為「客戶自建」,
唔可以標示做「Amoji功能」(品牌保護)
- 如果客戶要求「完全寫實」路線,合約應該加入額外費用反映恐怖谷風險評估
同專項工作量

### 1.3 B2C——AI動畫師工具/App Store插件
建議模式:Freemium + 訂閱
```
免費層:基礎8情緒,有浮水印匯出
訂閱層:小額月費,去水印+複合情緒+多角色儲存
一次性買斷:核心功能終身授權(俾唔想訂閱嘅用戶)
```

## Part 2:定價參考基準(同業對照)
之前提到 Hume AI 呢個參考點,佢哋嘅API定價喺$3至$500/月之間浮動,視乎用量。
你哋可以用呢個做起點,但要留意:
- 你哋嘅差異化(心理學規則庫、合規三機制內建)理論上支持喺同等用量下,定價
可以高於純情緒偵測類產品(Hume主要做偵測,你哋做生成+合規,價值主張唔同)
- 建議初期(冇市場數據支持嗰陣)定價偏向保守,累積咗實際使用數據/客戶反饋
先調整,好過一開始定得太高嚇走首批客戶

## Part 3:合約必備條款清單

```
- IP擁有權條款:明確Amoji引擎本身(規則庫、代碼)嘅IP歸屬,客戶只攞使用權
- 已故真人複製禁令:合約明文寫低,客戶違反即終止合約
- 心理健康包裝審查:客戶標榜「心理健康支援」用途,需要額外審查條款
- 親密/情慾定位分流:如客戶產品涉及呢類定位,獨立議價、獨立合約條款
- 生物特徵數據禁止回饋條款:客戶唔可以將用戶生物特徵數據傳俾Amoji引擎,
  亦都唔可以將Amoji輸出用嚟訓練偵測系統
- 合規三機制強制條款:AI披露/防沉迷/心理危機介入三個模組唔可以被客戶
  完全停用,只可以客製化措辭/介面
- 地區合規責任劃分:如果客戶產品進入中國大陸/歐盟/美國市場,邊方負責
  當地監管申報/備案,合約要明確劃分(建議:引擎合規基礎由你哋提供,
  當地市場准入申報由客戶自行負責)
```
