## Part 1:頭頸傾斜(Head Tilt)

### 1.1 側傾——最普遍嘅非語言訊號之一
<cite index="23-1">側頭傾斜喺人際溝通入面出現得非常頻密,大量實證文獻都討論過佢嘅意義。觀察自然互動場景,大約40%嘅人會側傾個頭;要求擺姿勢影相嗰陣,更加有接近四分之三嘅人會側傾。</cite>機械人研究直接證實:<cite index="23-1">側頭傾斜同友善、順從、吸引力嘅觀感有關,而且機械人做出呢個姿態,對用戶點樣睇呢個機械人有顯著影響。</cite>

**機制**:<cite index="23-1">側移個頭可以減輕眼神接觸帶嚟嘅喚起程度。</cite>

### 1.2 垂直傾斜——上揚 vs 低垂(有正式學術驗證)
<cite index="21-1">Mignault 同 Chaudhuri(2003)發現向下嘅頭部傾斜同順從/羞恥有關,向上嘅頭部傾斜就同支配/自豪有關。</cite>後續研究<cite index="25-1">確認咗上揚嘅頭代表快樂。</cite>

### 1.3 ⭐ 重要組合發現:低頭 + 直視 = 憤怒
呢個對你套系統極有價值,因為直接可以同 Layer E(眼球錨點系統)組合埋一齊:<cite index="24-1">研究發現上揚嘅頭代表支配同力量,但同一般假設相反,低垂嘅頭如果配合直視眼神,反而傳達支配感;第二個研究進一步發現,低頭配合直視眼神係傳達緊憤怒。</cite

**對你套系統嘅意義**:單一「頭部角度」或者單一「眼神方向」都唔夠——**必須將 Layer B(頭部角度)
同 Layer E(眼球錨點)組合睇**,先分得出:
- 低頭 + 眼神迴避(錨點偏移)= 順從/羞恥/傷心
- 低頭 + 眼神鎖定對方(錨點=對話對象)= 憤怒/挑戰

### 1.4 側傾嘅速度同伴隨表情,決定係好奇定懷疑
<cite index="26-1">慢速、刻意嘅側頭傾斜,配合瞇眼同中性或平板嘅表情,會被解讀做懷疑或者無聲嘅質疑。</cite>——呢個直接印證咗你之前「懷疑」情緒表嘅單邊眉毛/側目設計,而家可以加返一個「慢速側頭」嘅身體層確認動作。

## Part 2:肩膊(Shoulders)

### 2.1 塌肩/圓肩——傷心/低自信嘅可靠指標
<cite index="28-1">三藩市州立大學嘅研究發現,86% 嘅人喺塌肩姿勢下更加容易讀取負面記憶。</cite><cite index="32-1">抑鬱狀態通常透過身體表現出嚟——動作減少、肩膊塌陷、視線低垂。研究參與者被安排採用塌陷姿勢後,回報咗更多負面想法,並且使用同傷心/無助感相關嘅字眼。</cite>

### 2.2 聳肩/繃緊——恐懼/憤怒嘅共同特徵
跨情緒身體語言調查歸納出嘅具體模式:<cite index="35-1">恐懼:心跳明顯加快(頸部可見)、雙腿雙臂交叉郁動、肌肉繃緊(手/臂握緊、手肘向內收)、屏住呼吸、防禦性姿勢。憤怒:身體展開、手叉腰、雙手握拳、手掌向下、手指指向。</cite>

### 2.3 開放挺胸——自豪/自信嘅「姿勢密碼」
<cite index="28-1">將肩膊向後向下捲、打開胸口,呢個「自豪姿勢」係一個跨文化嘅高地位訊號。</cite>

### 2.4 六大情緒嘅身體姿態總表(可直接編碼)
一份兒童-機械人互動研究,將六大基本情緒嘅身體表現整理成清晰嘅對照表:<cite index="33-1">開心:主要透過臉部表現,偶爾有跳躍動作及/或張開舉起雙手,身體挺直,頭部端正向上。傷心:哭泣(雙手掩面)、靜止不動、頭望下、胸口收縮。驚訝:胸口擴張、冇特定模式嘅手部動作,可正可負。恐懼:眼神快速游移、臉部表情較弱、雙臂在胸前交叉。厭惡:主要透過臉部表現(伸脷)、身體遠離動作或者用手推開。憤怒:握拳、雙臂交叉、肩膊繃緊方正。</cite>

**跨資料集互相印證**:<cite index="35-1">傷心:身體下垂、身體縮小、彎腰駝背、軀幹前傾。</cite>兩組研究對「傷心=塌肩前傾」嘅描述完全一致,增加咗可信度。

## Part 3:呼吸(Breathing)—— Alba Emoting 缺口嘅正式補完

### 3.1 情緒改變呼吸嘅速率同深度
<cite index="41-1">負面情緒(焦慮、恐懼、傷心)會令呼吸速率上升;正面情緒(開心)都會令呼吸速率上升,但釋懷/放鬆嘅情緒會令呼吸速率下降。除咗速率變化,每種情緒仲會伴隨一種特徵性嘅呼吸模式——快而深嘅呼吸同興奮有關,快而淺嘅呼吸就同專注、恐懼、驚慌有關。</cite>

### 3.2 呼吸品質(唔止速率,仲有節奏規律性)
<cite index="44-1">緩慢嘅呼吸同放鬆有關;不規則嘅節奏、急速嘅呼吸、甚至屏住呼吸,就同更強烈嘅情緒(例如憤怒或恐懼)有關。</cite>

### 3.3 吸氣 vs 呼氣——邊段拉長,決定「提振」定「鎮定」
呢個係一個好實用嘅操作原則:<cite index="43-1">喺單一個呼吸循環入面,延長吸氣階段有提振/激活效果,延長呼氣階段就有放鬆/鎮定效果。</cite>

### 3.4 呼應返 Alba Emoting(文件8)
之前研究提過,Alba Emoting 嘅「效應器模式」由呼吸、姿勢、表情三部分組成,而且<cite index="56-1">教學次序必然係先教呼吸模式,再加姿勢,最後先加表情</cite>——而家呢份文件嘅呼吸/肩頸研究,正正將嗰個系統缺咗嘅兩塊(呼吸、姿勢)填番。

## Part 4:整合方案——Layer B 參數表

| 參數 | 說明 | 範圍 |
|---|---|---|
| `headTiltLateral` | 頭部側傾角度(左/右) | -1(左)至 +1(右),0=正中 |
| `headTiltVertical` | 頭部俯仰(上揚=支配/自豪,下垂=順從/傷心) | -1(下垂)至 +1(上揚) |
| `headTiltSpeed` | 側傾嘅速度(慢速側傾=懷疑,快速=一般好奇/確認) | slow / normal / quick |
| `shoulderHeight` | 肩膊高度(聳起=緊張恐懼,放鬆=中性) | 0(放鬆)至 1(聳起繃緊) |
| `shoulderRoundness` | 肩膊前捲程度(前捲=傷心/不安,後展=自豪/憤怒展開) | -1(前捲)至 +1(後展) |
| `chestExpansion` | 胸口擴張/收縮(擴張=驚訝/自豪,收縮=傷心/恐懼) | -1(收縮)至 +1(擴張) |
| `breathingRate` | 呼吸速率(相對中性嘅倍數) | 0.6(緩慢放鬆)至 2.0(急促) |
| `breathingDepth` | 呼吸深度(淺 vs 深) | shallow / medium / deep |
| `breathingRegularity` | 呼吸規律性(規律 vs 不規則/屏息) | regular / irregular / held |

### 情緒對照表(8個核心情緒 + 新增身體參數)

| 情緒 | headTiltV | shoulder | chest | breathing |
|---|---|---|---|---|
| 開心 | +0.3(微上揚) | 放鬆 | 微擴張 | 中速、深、規律 |
| 傷心 | -0.7(下垂) | 前捲塌陷 | 收縮 | 慢/淺、可能不規則(啜泣) |
| 憤怒 | -0.3(略低)**+ 直視錨點** | 繃緊後展方正 | 擴張 | 急促、不規則、可能屏息 |
| 恐懼 | -0.2 | 聳起繃緊 | 收縮 | 急促而淺 |
| 驚訝 | +0.2(瞬間後仰) | 瞬間聳起 | 瞬間擴張 | 短暫屏息後急促 |
| 厭惡 | 0,身體轉向側面 | 輕微後縮 | 收縮 | 正常偏淺 |
| 思考 | 側傾(方向不拘,個性化) | 放鬆 | 中性 | 慢速(專注時呼吸減慢) |
| 尷尬 | -0.4(低垂) | 前捲收窄 | 輕微收縮 | 略急促、淺 |
| 懷疑 | 側傾(慢速!)+ headTiltSpeed=slow | 中性 | 中性 | 正常 |

**特別規則**:憤怒嘅 `headTiltVertical` 必須同 Layer E 嘅錨點狀態連動——如果錨點鎖定對話對象
(直視),先顯示做憤怒;如果錨點迴避,同一個低頭姿態應該顯示做傷心/順從。**呢個係全個系統入面
一個罕有嘅、必須跨兩個 Layer 讀取先分得出情緒嘅例子**,值得喺實作時特別標註。

## Part 5:實作限制備註
呢個 Layer 需要肩頸/上身嘅渲染或者伺服馬達支援——你而家嘅 prototype(v1-v9)都係得個頭,
未有身體。實作呢層需要:
1. 2D 版本:擴充畫布,加返肩膊/胸口嘅簡化圖形,或者將現有頭像放到一個可以郁嘅頸部/肩膊底座上
2. 機械人版本:需要頸部同肩膊嘅伺服馬達(如果硬件設計有呢啲自由度)
3. 呼吸嘅視覺化(2D/3D 都啱用):可以用胸口區域嘅緩慢升降縮放嚟表達,唔需要複雜骨骼
