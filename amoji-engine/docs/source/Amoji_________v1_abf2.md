⚠️ 呢份係實務評估,唔係財務保證——實際執行結果視乎你投入嘅時間、技術學習
曲線、同市場反應。

## 直接答案:可以,而且你哋嘅系統設計本身就特別啱呢條路

呢個唔係巧合——你哋之前一個關鍵決策(「傳統確定性編程 vs AI模型」)——
淨係因為 Amoji 引擎係規則式(rule-based)、唔係要訓練機器學習模型,先令
「用Claude Code由零起家」呢件事變得現實可行。如果 Amoji 嘅核心係一個要
訓練嘅神經網絡模型,咁就真係需要GPU運算資源、數據、ML工程團隊——但你哋
而家嘅系統,本質上係JavaScript邏輯代碼加JSON數值表,呢個正正係Claude
Code最擅長嘅嘢。

---

## Part 1:Claude Code 可以做到邊個程度

### 完全可以由 Claude Code 一手包辦
```
- Phase 0-6全套核心引擎(合規骨架、情緒公式、口型覆蓋、劇本系統、人格系統)
- 全部Layer邏輯(B/E/G/W/CA/MT)嘅程式實現
- 2D/Three.js渲染器(而家29個prototype已經證明呢個技術棧完全可行)
- 資料結構、單元測試、基本CI流程
- App嘅前端UI/UX
- API/後端服務(如果需要,例如用戶帳戶、訂閱管理)
```

### Claude Code 做唔到,但你自己嘅背景剛好填補
```
- 精緻嘅3D角色美術資產(建模、材質、綁定)——但呢個正正係你自己二十年
  動畫經驗嘅強項,唔使外聘
- 最終嘅藝術判斷(邊個表情「感覺啱唔啱」)——你自己驗收
```

### 必須人手處理嘅行政步驟(Claude Code做唔到,但成本低)
```
- Apple Developer Program註冊(US$99/年)——如果做App Store插件
- App Store審核提交——需要人手操作,但流程本身唔收額外費
- 公司註冊(HK$3,895)
- 銀行開戶(需要親身,但你已經喺香港)
```

## Part 2:成本結構——真係可以做到「好少錢」

### 2.1 開發階段(Phase 0-6)嘅實際現金成本
```
Claude訂閱費(用嚟跑Claude Code)—— 每月固定費用,相對其他選項算低
Three.js/開發工具——全部免費開源
Blender(3D建模,如果唔用返你原有嘅動畫軟件)——免費
Git/GitHub——免費(公開倉庫)或者低成本(私人倉庫)
本機電腦——你應該已經有

估計:開發階段每月現金成本可以壓喺數百港元級數(主要係Claude訂閱費),
唔需要任何額外投資
```

### 2.2 上線階段嘅額外成本(視乎揀邊條產品線)
```
如果做B2C #1(AI動畫師工具,網頁版)——
  - 網站hosting:Vercel/Netlify/Cloudflare Pages有慷慨嘅免費層,初期夠用
  - 域名:每年約HK$100-200
  - 呢條線幾乎冇邊際成本——因為佢係「工具」,唔係「持續對話AI」,
    冇每個用戶都要燒緊LLM API費用嘅問題

如果做B2C #2(App Store插件,消費者聊天App)——
  - Apple Developer:US$99/年
  - 如果涉及即時對話功能,你需要接駁一個LLM(你自己或者第三方),
    呢個會產生按用量計費嘅API成本——呢條線嘅邊際成本明顯高過工具線
```

### 2.3 關鍵建議:B2C #1(動畫師工具)先係真正嘅「零成本起步」路線
呢個發現值得特別標明:你哋四條產品線入面,B2C #1(AI動畫師工具)先係
真正做到「幾乎冇持續營運成本」嘅一條——因為佢本質上係一個「將劇本/錄音
轉做動畫」嘅工具,唔係一個要即時同用戶對話嘅聊天機械人。用戶用你嘅引擎
處理佢哋自己嘅內容,你唔使幫佢哋負擔LLM API費用。

相反,B2C #2(App Store 陪伴聊天App)如果要做到「同用戶對話」,背後
一定要有個LLM幫手諗返嘢俾用戶睇,呢個LLM嘅API費用會隨住用戶量增加,呢個
成本結構同B2C #1完全唔同,唔啱做「用好少錢起步」嘅第一步。

## Part 3:建議嘅零/低成本啟動路線

```
Step 1(現在-1個月):
  維持你依家嘅正職(室內設計)做收入基礎,Amoji用業餘時間/Claude Code開發
  —— 呢個本身已經係你之前一路採取嘅做法,冇需要改變

Step 2(1-4個月):
  用Claude Code逐個Phase(0至6)開發核心引擎,跟返之前寫低嘅detailed
  checklist,唔使外聘任何開發者

Step 3(4-6個月):
  用你自己嘅動畫背景,做一至兩個示範角色嘅3D美術資產(唔使好多,一個靚嘅
  demo已經夠用嚟展示)

Step 4(6個月左右):
  將B2C #1(AI動畫師工具)做成一個網頁版demo,免費/近乎免費host,開始
  搵首批用戶(可以由你自己嘅動畫圈子/YouTube觀眾開始)

Step 5(視乎Step 4反應):
  有咗實際用戶反應同demo之後,先評估:
  (a) 繼續自資擴展B2C
  (b) 再申請Cyberport/HKSTP(呢時你哋已經有實際產品,申請成功率應該更高)
  (c) 直接接觸B2B客戶(有咗demo,先有嘢俾人哋睇)
```

呢個路線嘅核心邏輯:唔使一開始就追求資助/融資,而係用你自己嘅時間
(唔係現金)做最貴嘅資源投入,用Claude Code大幅壓縮開發需要嘅人力成本,
喺你有咗實際產品同用戶反應之後,先至去搵資助/投資——呢個時候你哋嘅
議價能力仲會更加強(有demo好過得個橋)。
