# Amoji 系統規格 —— 講嘢速度與停頓嘅情緒差異研究

呢份研究可以擴充你哋 Layer 0(劇本)/未來語音整合部分——同你哋AI Video
Actor Engine技術規格提到嘅「聲音語氣同塊面對唔上」問題直接相關。

---

## Part 1:核心發現——一條可以直接寫成公式嘅關係

<cite index="29-1">對話節奏隨互動狀態變化:語速隨喚醒度(arousal)同支配度(dominance)
上升而加快,停頓比例就隨之下降。</cite>

呢個係最重要嘅發現——可以直接對應你哋Layer 1嘅arousal參數:
```
speechRate = baseRate * (1 + arousal * rateMultiplier - dominance * 0.1)
pauseRatio = basePauseRatio * (1 - arousal * pauseReductionFactor)
```

## Part 2:各情緒嘅具體聲學特徵

### 2.1 恐懼——快、短、少停頓
<cite index="33-1">恐懼同時提升平均基頻(F0)同基頻變異度,語速加快、講話時長縮短、
停頓更少更短、音量提高。</cite>

### 2.2 傷心——同恐懼相反,減速
<cite index="36-1">語速喺講者傷心嗰陣傾向減慢,喺恐懼嗰陣就傾向加快。</cite>

呢個直接印證恐懼同傷心雖然都係負面效價,但arousal完全相反嘅設計原則
——你哋Layer 1本身已經將valence同arousal分開,呢個發現進一步證實呢個
設計嘅必要性。

### 2.3 抑鬱(病理性狀態,俾你哋參考極端情況)
<cite index="32-1">抑鬱嚴重程度同語速、轉換停頓時長有顯著相關——抑鬱越嚴重,
語速越慢、轉換停頓(switching pause)越長。</cite>

---

## Part 3:停頓嘅修辭功能——唔止係「冇聲」咁簡單

<cite index="30-1">停頓(靜默同有聲嘅)係強而有力嘅情緒表達工具:重要句子前面
停頓可以製造期待感;情緒陳述之後嘅靜默,俾聽眾消化其份量;停頓仲可以
改善清晰度,幫聽眾處理複雜概念。</cite>

對你哋Layer T(延遲橋接系統)嘅意義:呢個直接支持你哋之前設計嘅「思考
姿態」邏輯——停頓唔止係「AI處理緊嘢」嘅technical delay,喺演出設計上,
刻意加插停頓本身就係一種情緒表達手法,尤其係喺講重要嘢之前/之後。

---

## Part 4:誠實線索——有聲停頓(um/uh)嘅細微分別
<cite index="30-1">研究顯示欺騙性言語會有更多有聲停頓(例如「um」)多過「uh」。</cite>

對你哋文件11(延遲橋接填充語)嘅意義:如果你哋將來想令角色顯得更加
「誠實/可信」,填充語庫可以刻意偏向用「uh」少用「um」——呢個係一個好
細微但有研究支持嘅細節。

---

## Part 5:一個時序上嘅細微發現——句尾比句頭更快傳達某啲情緒
<cite index="36-1">開心同厭惡,聽眾聽到句尾先識別會快過聽句頭——但恐懼、憤怒、
傷心、中性,就唔受呢個「句子先後段」嘅影響。</cite>

對Layer V(共同發音)嘅意義:如果角色要表達開心或者厭惡,呢個發現
提示緊你哋——句尾嘅表情/聲調變化,可能比句頭嘅變化,對聽眾嘅情緒
識別更加關鍵,值得喺劇本時序設計加強句尾嘅表現力。

---

## Part 6:年齡對聲學特徵嘅影響——同你哋人口特徵文件互相引證
<cite index="29-1">年齡組別會影響音高同韻律節奏——唔同年齡組別(18-29/30-59/60+)
喺平均基頻、語速、停頓比例分佈上都有差異。</cite>

呢個直接呼應之前人口特徵情緒表達差異清單文件——年齡唔止影響面部表情
幅度,亦都影響聲音本身嘅節奏特徵,建議將呢個維度都納入 Demographic
Modulation 子系統。

## Part 7:整合建議——擴充 Layer 0/Layer T

```
ScriptLine擴充欄位(建議):
{
  text: "...",
  emotion: "fear",
  intensity: 0.8,
  speechPacing: {
    rateMultiplier: 1.3,      (由arousal/dominance公式推導,Part 1)
    pauseRatio: 0.6,          (同上)
    prePausePlacement: "before-key-phrase",  (修辭性停頓,Part 3)
    fillerBias: "uh-over-um"  (可信度相關嘅填充語偏好,Part 4)
  }
}
```
