# Amoji Studio(暫名)—— B2C AI 動畫師工具 MVP 產品規格

## 目標用戶
獨立動畫師、VTuber、內容創作者、細型遊戲工作室——想快速做一個會講嘢、有情緒嘅 3D 角色,
但唔想/唔識做完整嘅 3D 建模同骨架綁定。

## 核心工作流程(三步曲)
```
1. 輸入        →  2. Amoji 引擎處理        →  3. 輸出
真人臉部影片        套用你套 Expression DNA        會講嘢、有情緒嘅
(用手機拍攝)        (情緒/口型/眼神/頸肩)         3D 角色影片/即時串流
或者：輸入劇本文字     + AI 換臉(套用去自訂角色)
     (AI生成情緒/口型)
```

## MVP 功能範圍(刻意精簡,唔做齊成套架構)

### 必須有(V1)
- **臉部動態捕捉輸入**:用手機前置鏡頭,錄一段真人講嘢嘅片段(對應你套 24 點輕量版點位系統)
- **口型自動同步**:文字/語音轉口型(Preston Blair 10 口型,文件15)
- **基礎情緒疊加**:8 個核心情緒(開心/傷心/憤怒/驚訝/恐懼/厭惡/思考/懷疑),用戶手動揀
  或者由文字情緒分析自動判斷
- **AI 換臉**:將動態捕捉到嘅表演,套用去用戶自訂/揀選嘅 3D 角色臉部
- **匯出**:MP4 影片,或者 glTF/ARKit blendshape 格式(俾用戶自己攞去遊戲引擎/其他工具用)

### 唔喺 MVP 範圍(留返後續版本)
- 複合情緒引擎(文件9 Part B)
- 心情引擎/Layer -1(需要更長時間嘅用戶行為數據先有意義)
- 微表情洩漏/Step-Out(文件6、8)——呢啲屬於「進階真實感」功能,MVP 先用基礎版本
- 頸肩呼吸(文件17、18)、手勢層(文件19)——V2 先加,MVP 先得頭部表演
- 五個人格檔案系統——MVP 用戶一次過用一個角色,人格系統留返俾 SDK/B2B 版本

## 差異化賣點(相對於現有工具,例如 Live2D、iClone、Reallusion 呢類)
- **心理學根據嘅情緒規則庫**,唔係靠純 AI 生成模型「估估下」個表情啱唔啱
- **你二十年動畫經驗轉化成嘅規則**,係其他純技術背景嘅工具冇嘅資產

## 建議定價模式(參考文件20商業定位入面提到嘅訂閱制邏輯)
- 免費版:基礎 8 情緒、有浮水印匯出
- 訂閱版(月費):去水印、進階情緒(複合情緒)解鎖、多角色儲存
- 一次性買斷(俾唔想訂閱嘅用戶):核心功能終身授權,進階功能另購

## 技術棧(對應文件22)
Three.js(網頁優先,零安裝)+ 核心引擎邏輯(JSON驅動,獨立於渲染層,方便日後遷移去 Unity 版)

## 建議時間線
- 4-6 週:核心 pipeline 打通(mocap輸入 → 口型/情緒映射 → 3D 渲染輸出),用一個固定示範角色
- 4 週:AI 換臉整合
- 2-4 週:UI/UX、匯出格式、定價系統
- 總計約 3-4 個月做到可以畀首批用戶試用嘅版本
