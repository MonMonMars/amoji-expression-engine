# Amoji 系統規格 —— Part Q:全身語言與步態(Layer W —— 行走風格)

## 開場:一個奠基性嘅科學發現
1973年,瑞典心理學家 Gunnar Johansson 做咗一個經典實驗:<cite index="18-1">將反光貼紙貼喺一個人嘅手腕、手肘、肩膊、腳踝、膝頭、髖關節等關節位置,喺全黑環境入面拍攝呢個人行走——參與者睇靜態相完全睇唔出係人形,但一播片就即刻認得出係一個人喺度行緊路。</cite><cite index="14-1">呢個「光點行者」(point-light walker)識別,喺短至 200 毫秒嘅曝光時間就已經做得到。</cite>

**呢個發現對你套系統嘅根本意義**:身體動作本身(唔使靠塊面)已經帶住足夠嘅情緒/身份訊息——
證明咗你而家做緊嘅 Layer B(頸肩)、Layer G(手勢)方向啱,而家加返 Layer W(步態)就補完
最後一大塊「純靠動作本身表達情緒」嘅拼圖。

## Part 1:情緒對步態嘅具體量化影響(可直接編碼)

### 1.1 速度變化(有精確數字)
<cite index="3-1">憤怒同快樂令步速加快大約 20%,傷心就令步速減慢大約 10%,呢啲全部相對於中性步行嚟講。</cite>
具體數值:<cite index="3-1">中性步速 1.14 m/s;憤怒 1.24 m/s;快樂 1.25 m/s;恐懼 1.22 m/s;傷心 1.12 m/s。</cite>

### 1.2 質性特徵總結(跨多份研究互相引證)
<cite index="6-1">Montepare 等人(1987)發現:快樂嘅步姿特徵係較快嘅步速;憤怒嘅步姿特徵係較多手臂擺動、
較重嘅腳步聲、較長嘅步幅;傷心嘅步姿特徵係手臂擺動明顯減少。</cite>

<cite index="7-1">憤怒通常伴隨重腳步聲;開闊、舒展嘅軀幹傳達開心,減少嘅手臂擺動暗示傷心;憤怒同快樂嘅步姿
都有大幅度嘅手臂郁動,但速度更快;相反,傷心嘅步姿特徵係手臂擺動減少、速度較慢、步幅較短,
但仍然涉及成隻手臂嘅郁動。</cite>

### 1.3 ⭐ 恐懼嘅步態有一個獨特、唔同於其他情緒嘅特徵——「遠端手臂擺動」
呢個發現特別重要,因為恐懼嘅手部動作機制同開心/憤怒完全唔同:<cite index="7-1">當人感受到恐懼,佢哋
傾向表現出較短、較快嘅步伐,同減少嘅手臂郁動,而且呢種減少嘅郁動主要集中喺前臂位置。</cite>
<cite index="6-1">恐懼透過快而短嘅步伐、加上更多遠端(前臂為主)嘅手臂擺動嚟表達。</cite>

**對你套系統嘅意義**:呢個唔止係「幅度細啲」咁簡單,而係**手臂郁動嘅解剖學來源都唔同**——
開心/憤怒係「成隻手臂由肩膊帶動」嘅擺動,恐懼係「淨係前臂喺手肘位置郁」,肩膊/上臂反而
相對固定。你套系統嘅手勢層(Layer G)可以加一個 `armSwingOrigin` 參數:`shoulder`(全臂,
開心/憤怒用)vs `elbow`(遠端,恐懼用)。

### 1.4 垂直彈跳(Vertical Bounce)——另一個關鍵區分特徵
<cite index="8-1">開心嘅步姿有明顯嘅彈跳感、較快嘅步速、同一種「搖擺」感;傷心嘅步姿肩膊下垂、手臂擺動
極少、步速慢、彈跳好少;憤怒嘅步姿有誇張嘅手臂擺動、較大嘅彈跳、快速嘅步速;恐懼嘅步姿手臂
郁動主要局限喺前臂、步速較慢。</cite>研究仲補充:<cite index="8-1">傷心嘅垂直彈跳幅度明顯細過憤怒。</cite>

### 1.5 趨避行為(Approach/Avoidance)——步態會回應情緒刺激嘅性質
<cite index="9-1">當參與者接觸到唔悅嘅圖像(包括攻擊、傷殘、污染主題),佢哋會表現出迴避傾向,例如步速變慢、
步幅縮短;當接觸到愉悅圖像(例如色情內容),就出現相反效果,步速加快。</cite>

**對你套系統嘅意義**:呢個直接可以掛落 Layer E 嘅錨點系統——如果角色行緊去一個「正面錨點」
(想接近嘅嘢/人),步速應該自然加快;行緊去一個「負面錨點」或者刻意迴避,步速應該減慢/
路徑變得唔直接。

### 1.6 難易度排名——傷心最易認,憤怒最難認
<cite index="8-1">研究發現傷心係最容易從步姿被認出嚟嘅情緒,憤怒就係最難嘅。研究者解釋,步態提供嘅係自發、
習慣性嘅線索,唔似臉部表情咁可以被刻意控制。</cite>

**對你套系統嘅意義**:如果你套系統想俾用戶「一眼認出」某個情緒,傷心用步態表達嘅效果會
特別好;但憤怒單靠步態可能唔夠清晰,建議必須配合 Layer B(肩頸繃緊)/Layer G(握拳)
一齊表達,唔可以淨係靠 Layer W。

### 1.7 「快樂優越效應」——快樂嘅生物運動特別容易被感知
<cite index="17-1">研究發現快樂嘅光點行者,比起傷心、憤怒或者中性嘅行者,被辨識得更快、更準確——呢個現象
稱做「快樂優越效應」。</cite>

## Part 2:健康/心理狀態嘅步態訊號(補充,人格/心情系統參考用)
<cite index="5-1">抑鬱狀態嘅人通常表現出較慢嘅步速同減少嘅手臂擺動;焦慮狀態可能表現出不穩定/不規則嘅步伐
模式。</cite>另有臨床案例提到:<cite index="5-1">PTSD 患者嘅步態分析會揭示出過度警覺——透過僵硬嘅
動作模式反映出嚟。</cite>

**對你套系統嘅意義**:呢個可以直接對應之前嘅「心情引擎」(Layer -1)——一個持續處於「低落
心情」底色嘅角色,就算劇本情緒係中性,佢嘅**待機步態基線**都應該悄悄帶住較慢步速/較少手臂
擺動,唔使等到 Layer 1 明確觸發「傷心」情緒先反映出嚟。

## Part 3:整合方案——Layer W 參數表

| 參數 | 說明 | 中性基準 |
|---|---|---|
| `walkSpeed` | 相對中性步速嘅倍數 | 1.14 m/s = 1.0x |
| `strideLength` | 相對步幅 | 1.0x |
| `cadence` | 步頻(步/分鐘) | 因人而異,用相對值 |
| `armSwingAmplitude` | 手臂擺動幅度 | 1.0x |
| `armSwingOrigin` | 擺動源頭:`shoulder`(全臂)/ `elbow`(遠端前臂) | shoulder |
| `verticalBounce` | 垂直彈跳幅度 | 1.0x |
| `footstepWeight` | 腳步聲/力度(輕footed vs 重踏) | neutral |
| `pathDirectness` | 路徑直接度(受 Layer E 錨點嘅趨避性質影響) | direct |

### 情緒對照表(基於 Part 1 數據整理)

| 情緒 | walkSpeed | strideLength | armSwing(幅度/來源) | verticalBounce | footstepWeight |
|---|---|---|---|---|---|
| 中性 | 1.0x | 1.0x | 1.0x / shoulder | 1.0x | neutral |
| 開心 | 1.1x | 1.15x(extended) | 1.4x / shoulder | 1.4x(明顯彈跳+搖擺) | light |
| 憤怒 | 1.2x | 1.2x(long) | 1.5x / shoulder(vigorous) | 1.3x | heavy(stomping) |
| 傷心 | 0.85x | 0.8x(shorter) | 0.35x / shoulder(但幅度極少) | 0.4x(細) | light,拖行感 |
| 恐懼 | 0.95x(短快步,非簡單「慢」) | 0.6x(short quick) | 0.4x / **elbow(遠端)** | 0.5x | quick,不穩 |

**關於恐懼嘅速度備註**:研究入面恐懼嘅量化步速(1.22 m/s)接近憤怒/開心,但質性描述係
「短而快嘅步伐」——即係話唔係「行得慢」,而係「用好多細碎快步」,同「大步流星」嘅開心/
憤怒喺步態質感上完全唔同,就算量化速度接近都好。建議用 `strideLength` 細 + `cadence` 高
嚟共同表達呢種「碎步急行」感,而唔淨係郁 walkSpeed 一個參數。

## Part 4:同現有系統嘅銜接

```
Layer W · 行走風格(新增)
  ├─ 讀取 Layer 1(情緒強度值)→ 套用上面對照表
  ├─ 讀取 Layer -1(心情)→ 修改待機步態基線(例如低落心情令基線步速持續偏慢)
  ├─ 讀取 Layer E(眼球錨點)→ 若角色正朝住錨點行走,錨點嘅「正/負」性質調整 pathDirectness
  ├─ 讀取 Layer G(手勢)→ armSwingOrigin 同 Layer G 嘅 Adaptor/Affect Display 共用手臂控制權,
  │                      避免步行時嘅手臂擺動同靜態手勢系統打架(需要類似口型系統嘅覆蓋邏輯)
  └─ 讀取 Layer P(人格檔案)→ 人格決定步態嘅整體「音量」(例如企業文件人格嘅步態變化幅度
                             應該全面收窄,唔應該有戲劇化嘅開心搖擺或者憤怒踏步)
```

## Part 5:站立時嘅重心分佈/姿態搖晃(Postural Sway)

### 5.1 重心嘅基本概念
<cite index="27-1">重心(COG)喺人類站立姿勢入面,大約位於第二薦椎(S2)前方——呢個位置並非固定,會隨動作、
四肢位置、身體如何分配施力而持續移動。</cite><cite index="27-1">單腳支撐嗰陣,重心會偏向支撐腳嗰邊;行走本質上就係持續管理住一個喺移動中嘅支撐基礎上不斷
轉移嘅重心。</cite>

### 5.2 焦慮/威脅會增加姿態搖晃(Postural Sway)嘅基線
<cite index="32-1">情緒狀態、自主神經系統活動、同軀體神經系統活動之間,有強烈嘅證據顯示互相關聯。喚醒程度提升,
會伴隨靜止站立嗰陣搖晃速度同幅度嘅變化。</cite><cite index="33-1">高焦慮嘅兒童,姿態搖晃模式顯示佢哋嘅平衡整體較唔穩定,需要更多注意力資源。</cite>

### 5.3 ⭐ 「凍結反應」——面對直接威脅時搖晃反而會減少
呢個係一個重要嘅反直覺發現:<cite index="32-1">研究發現面對憤怒表情嗰陣,身體搖晃顯著減少(相對於開心
或者中性表情),呢種減少嘅身體搖晃被解讀做「凍結行為」——凍結反應令個體可以優先偵測相關資訊,
然後先至調動反應。</cite>

**對你套系統嘅意義**:呢個提供咗一個重要嘅時序區分——
- **持續性焦慮/緊張心情(Layer -1)**:應該表現做**搖晃幅度提升**(坐立不安、唔穩定嘅待機基線)
- **突發、直接面對嘅威脅刺激**(例如 Layer 0 劇本標記緊「受到威脅」):應該表現做**搖晃瞬間
大幅減少**(凍結)——呢個同持續焦慮嘅表現方向完全相反,唔可以用同一條參數曲線處理

### 5.4 高度威脅模型——具體行為變化
<cite index="30-1">當一個人企喺高處平台邊緣,會出現強烈嘅情緒反應:狀態焦慮上升、交感神經喚醒上升、對平衡嘅
自我效能感下降;同時亦都會出現廣泛嘅注意力轉移——更多注意力會投放喺自己動作嘅內在機制、
威脅相關嘅刺激、以及調節情緒狀態嘅策略之上。</cite>

### 5.5 整合建議:新增 `posturalSway` 參數
| 狀態 | posturalSway 幅度 | 說明 |
|---|---|---|
| 平靜/中性待機 | 低,規律 | 對應 Layer I 已有嘅呼吸/次要動作 |
| 持續焦慮心情(Layer -1) | 提升,不規則 | 疊加喺 Layer I 之上嘅額外搖晃 |
| 突發直接威脅(劇本明確標記) | **瞬間銳減**(凍結) | 覆蓋(override)上面兩者,短暫、明確嘅生理反應 |
| 高度/失衡威脅情境 | 提升,伴隨姿態收窄(縮埋身) | 特殊情境參數,留返俾未來擴充(例如角色企喺邊緣/高處嘅場景) |


## Part 6:實作限制備註

Layer W 需要「移動」呢個維度,你而家嘅 prototype(v1-v12、3D v1-v3)全部係企定嘅角色。
實作呢層需要:
1. 3D 骨架動畫(walk cycle)——呢個屬於標準動畫技術,你嘅二十年動畫背景喺呢度可以直接發揮
2. 如果係機械人(輪式/雙足),要留意物理限制——輪式機械人冇「步態」可言,但可以用移動速度/
加速度嘅變化模式嚟類比表達(急速轉向、猶豫停頓等),呢個概念上同 Layer W 一致,只係執行
方式唔同
3. 建議下一階段可以做一個簡化嘅 2D「側面行走剪影」demo,用返你之前 pixel prototype 嘅手法,
快速驗證呢個對照表嘅視覺效果
