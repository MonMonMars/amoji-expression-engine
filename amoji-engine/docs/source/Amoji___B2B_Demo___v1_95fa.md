## Demo 應該點樣「amazing」——三個必備嘅震撼位

### 震撼位一:「呢個唔止識做表情,佢識演戲」
唔好淨係show一個表情列表——用返劇本系統、複合情緒引擎、心情引擎,做一段
有起承轉合嘅小劇情(例如:平靜→聽到壞消息→震驚→強忍傷感→重新振作),
等對方睇到「呢個唔止係換表情圖,佢有連戲」。

### 震撼位二:「你哋成日都跌落嘅恐怖谷,我哋有整套對策」
呢個係你哋最強嘅差異化——冇任何競爭對手做過咁完整嘅恐怖谷研究。Demo入面
加一個環節,直接show「一致性原則」:同一個角色,示範「一致 vs 不一致」,
然後講一句:「呢個唔係美術問題,呢個係我哋成套系統設計嘅核心。」

### 震撼位三:「同一套引擎,你想要咩風格都得」
用返十級系統 + Layer CA——即場切換風格(anime/低多邊形/寫實)、切換角色
類型(人類/動物/物件),證明「你哋唔使幫每個角色重新設計一套邏輯」。
