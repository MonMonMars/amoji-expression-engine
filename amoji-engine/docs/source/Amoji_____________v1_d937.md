## 圖表 A:情境模式總覽——邊個情境,邊個 Layer 話事

| 情境 | 主導 Layer | 眼神/錨點行為 | 身體移動 | 備註 |
|---|---|---|---|---|
| **待機(Idle)** | Layer I | 隨機慢速游移(冇特定目標) | 呼吸+次要動作,3-4變體90秒輪換 | 常駐底層,永遠運行 |
| **一對一對話 · 講緊嘢** | Layer E(Dyadic) | 錨點在「望對方/望開」交替,約各半時間 | 手勢配合語音(Illustrator) | 開口前先短暫望開(組織語言) |
| **一對一對話 · 聆緊嘢** | Layer E(Dyadic) | 持續鎖定對方,約75%時間,夾雜短暫移開 | 較靜態,可有點頭(Regulator) | 對方情緒高峰時瞳孔可同步放大 |
| **回合轉換(Turn-End)** | Layer E | 望向對方(交還話語權訊號) | — | 明確觸發點,唔係漸變 |
| **回合開始(Turn-Start)** | Layer E | 短暫 gaze aversion | — | 對應思考模式嘅眼神移離 |
| **演講/簡報(大場合)** | Layer E(Presentation) | 三角掃視,多錨點,每點3-5秒 | 講者三角:位置隨劇本結構轉換(覆蓋情緒步態) | 唔可以用日常步態嘅誇張搖擺 |
| **演講/簡報(細場合/建信任)** | Layer E(Presentation) | 一人一完整思路,唔頻密掃視 | 較克制嘅移動 | 子模式選擇,視乎人格/場合 |
| **視像/鏡頭場景** | Layer E(Camera Mode) | 錨點鎖定虛擬鏡頭,唔係螢幕人臉 | 上半身為主 | 反直覺但有實證支持 |
| **行走/移動** | Layer W | 錨點可影響 pathDirectness(趨避) | 步速/步幅/手臂擺動隨情緒 | 見圖表 B |
| **AI 延遲/思考中** | Layer T | 眼神上移/側移,幅度隨延遲遞增 | 維持呼吸底噪,可有摸下巴等 Adaptor | 有填充語配合 |
| **突發威脅** | Layer B(覆蓋) | — | 姿態搖晃瞬間銳減(凍結) | 覆蓋持續焦慮嘅搖晃基線 |

## 圖表 B:情緒 × 全部 Layer 參數矩陣(核心對照表)

| 情緒 | 臉部(brow/eye/mouth) | 瞳孔調變 | accessoryMuscle(頸肩呼吸) | 步態(speed/stride/arm) | Affect Display(手勢) |
|---|---|---|---|---|---|
| **中性** | 全部0 | 0% | 0.1(低) | 1.0x / 1.0x / shoulder | 雙臂自然垂放 |
| **開心** | 眉0,瞇眼,嘴角大幅上揚 | +3~8% | 0.1 | 1.1x / 1.15x / shoulder,大幅彈跳 | 雙臂張開上揚 |
| **傷心** | 眉內聚上揚,眼瞼下垂,嘴角下垂 | +4% | 0.15 | 0.85x / 0.8x / shoulder但幅度極少 | 環抱身體(自我安慰) |
| **憤怒** | 眉下壓聚攏,眼瞇,嘴唇壓緊 | -3~-5% | 0.75(高) | 1.2x / 1.2x / shoulder,重踏 | 握拳,叉腰,展開佔空間 |
| **恐懼** | 眉上揚聚攏,眼睜大,嘴橫拉 | -3% | 0.85(最高) | 0.95x / 0.6x碎步 / **elbow(遠端)** | 雙臂交叉抱緊胸前 |
| **驚訝** | 眉大幅上揚,眼大睜,嘴垂直張開 | 最大放大 | 0.4(瞬間) | 短暫變化 | 手掩口/雙手舉起 |
| **厭惡** | 眉輕壓,鼻皺起,嘴角下拉 | +1~3% | 中等 | 身體遠離動作 | 推開手勢 |
| **思考** | 眉不對稱,眼神側上移 | 輕微 | 0.05(最低) | 通常靜止,踱步可用慢速 | 摸下巴(Adaptor) |
| **懷疑** | 單邊眉高,側目瞇眼 | — | 低 | 慢速側頭(非步態) | 抱手臂(輕度) |
| **尷尬** | 眉微揚,眼神迴避,腮紅 | — | 0.3 | 步伐可能猶豫 | 玩頭髮/摸頸背(Adaptor) |

**⭐ 關鍵交叉規則(必須跨 Layer 讀取,單一 Layer 判斷唔到)**:
- **低頭 + 眼神直視錨點** = 憤怒/挑戰;**低頭 + 眼神迴避錨點** = 傷心/順從(Layer B × Layer E)
- **憤怒單靠步態辨識度最低**,必須配合 Layer B(肩頸繃緊)/ Layer G(握拳)先夠清楚
- **恐懼嘅手臂擺動嚟自手肘、唔嚟自肩膊**,呢個質感分別本身就係恐懼嘅辨識特徵(Layer W)
- **突發威脅令姿態搖晃瞬間銳減**(凍結),同持續焦慮嘅搖晃增加方向相反(Layer B 覆蓋規則)

## 圖表 C:時刻/時序觸發表(唔限情緒,任何情緒都適用嘅時間軸規則)

| 時刻 | 觸發行為 | 對應 Layer | 時序原則 |
|---|---|---|---|
| 講嘢開始前 0.1-0.3秒 | 呼吸先郁,先於姿勢,先於表情 | Layer B → 姿勢 → 表情 | Alba Emoting 驗證嘅生理時序 |
| 情緒洩漏(壓抑狀態下) | 先眼部/眉毛閃現,後嘴部動作蓋過 | Layer 3 | 「先眼後口」微表情研究 |
| 情緒轉換之間 | Step-Out 過渡曲線,唔可以瞬間切換 | Layer 3 | 對應 Alba Emoting 離場程序 |
| AI 延遲 0-0.3秒 | 冇特別行為,維持殘留狀態 | Layer T | 短延遲唔使填充 |
| AI 延遲 0.3-1秒 | 轉輕度專注待機,眼神輕微上移 | Layer T | — |
| AI 延遲 1-3秒 | 沉思填充語+深度思考眼神+瞳孔輕微放大 | Layer T | — |
| AI 延遲 >3秒 | 補充第二句填充語(時間申請型) | Layer T | 避免重複同一句 |

| 對話回合開始 | 短暫 gaze aversion(組織語言) | Layer E(Dyadic) | Kendon研究 |
| 對話回合結束 | 望返對方(交還話語權) | Layer E(Dyadic) | Kendon研究 |
| 長回合語句間停頓 | 短暫望向對方(確認對方跟到) | Layer E(Dyadic) | 「檢查式」凝視 |
| 演講掃視 | 每個錨點停留3-5秒,平滑轉移 | Layer E(Presentation) | 三角掃視法 |
| 演講段落轉換 | 身體移去下一個劇本標記位置 | Layer W(覆蓋模式) | 講者三角 |

## 使用建議
- **圖表 A** 俾你判斷「而家系統應該用邊個模式」
- **圖表 B** 俾你判斷「呢個情緒,每個 Layer 應該點郁」——呢個係最常用嘅實作查閱表
- **圖表 C** 俾你判斷「呢個時刻,唔理咩情緒,應該觸發咩」——時序類規則,同情緒正交獨立

三張表合埋一齊用嘅邏輯:**先查圖表A定情境模式 → 用圖表B攞情緒嘅底層參數 → 用圖表C加返
時序觸發嘅細節** = 完整輸出。
