## Part 1:IP 策略——邊啲部分應該點保護

### 1.1 核心原則:唔係樣樣都要申請專利
<cite index="18-1">你唔可能一次過將所有嘢都申請專利,亦都唔應該咁做。應該集中喺:
(1) 競爭對手最難繞過嘅特徵;(2) 你營收模式嘅核心技術;(3) 商業壽命最長嘅技術。
唔係所有嘢都需要專利——有啲嘢用商業機密保護反而更好。專利同商業機密嘅關鍵分別:
專利要求你公開披露發明嘅運作方式(呢個係你同政府之間嘅交易),商業機密就唔使公開。</cite>

### 1.2 建議分類(套用去你哋嘅實際資產)

| 資產 | 建議保護方式 | 理由 |
|---|---|---|
| Layer架構嘅整體設計(例如「情緒生成 vs 用戶偵測分離」嘅系統架構) | 可考慮專利 | 具體技術系統,有非顯而易見嘅技術效果 |
| M1-M21肌肉編號、情緒x肌肉幅度矩陣嘅具體數值 | 商業機密 | 純數據/數值表,專利保護唔到,但公開咗就競爭對手可以直接抄 |
| Layer CA(角色原型適配層)嘅整體架構概念 | 可考慮專利 | 「同一套引擎跨物種/物件」呢個系統設計方法,較有機會符合非顯而易見性 |
| 十級Surface Renderer嘅分級方法論 | 商業機密為主 | 分級概念本身較難單獨申請專利,但作為完整方法論可以做營業秘密 |
| 品牌名「Amoji」、slogan | 商標註冊 | 呢個明確、成本低、保護效果直接 |
| 全部程式碼、文件本身 | 版權(自動產生,但建議做正式登記加強執法能力) | 文字/代碼作品自動有版權,登記令訴訟時更有力 |

### 1.3 一個對你哋非常有利嘅市場發現
<cite index="24-1">一間有受保護IP同獨有數據嘅AI軟件公司,同一盤運行喺租用模型同公開數據上面嘅相同
業務相比,估值倍數通常高2至4倍。</cite>

呢個直接證實咗你哋之前「AI vs傳統編程」嗰個決策嘅商業價值——你哋刻意用確定性
規則(而唔係借第三方AI模型「幫手諗」),正正令你哋符合呢個「受保護IP」嘅定義,
而唔係好似好多AI初創咁,只不過係包裝緊第三方API嘅「轉售商」。

### 1.4 專利對估值嘅實際影響(有數據支持)
<cite index="18-1">天使輪有專利嘅初創,估值平均高93%;早期有專利嘅初創,籌到嘅資金平均多73%。</cite>
<cite index="24-1">有專利嘅公司,獲得早期資金嘅機會高10.2倍。</cite><cite index="21-1">獨立IP審計可以
令估值倍數提升15%至20%。</cite>

### 1.5 實際成本參考
<cite index="25-1">一個合理嘅種子輪前IP套餐——一個臨時專利申請、兩個商標、一份IP轉讓範本、
一份保密協議範本——通常需要5,000至10,000美元。</cite><cite index="18-1">臨時專利申請
成本由65美元(DIY)到5,000美元(用律師)不等。</cite>

## Part 2:估值——現實情況同框架(唔可以俾你一個假嘅精確數字)

### 2.1 你哋目前處於邊個階段?
老實講,依家嘅 Amoji 未有:實體公司註冊、實際營收、付費客戶、已完成嘅完整產品——
呢個階段唔係「種子輪」,而係更早嘅「概念驗證/預種子」階段(你哋有嘅係:極之
詳盡嘅研究/規格文件、多個可運行嘅 prototype、一套一致嘅商業論述)。

### 2.2 2026年市場參考數字(俾你一個大概概念,唔係你哋嘅實際估值)
<cite index="20-1">2026年美國種子輪嘅中位數估值大約1,790萬美元。</cite><cite index="19-1">
AI初創嘅種子輪估值,通常比非AI同類公司高42%。</cite><cite index="21-1">種子階段AI公司
以10-25倍營收嘅估值成交,對應post-money估值1,000-1,500萬美元——但呢個區間好闊,
關鍵洞見係:同一階段入面嘅估值差異,大過唔同階段之間嘅差異。</cite>

⚠️ 呢啲數字嘅前提係「已經有種子輪級數嘅產品/團隊/初步吸引力」——你哋目前仲未到
呢個階段,呢啲數字純粹俾你哋一個「呢個行業大概咩水平」嘅參考,唔可以套用做你哋
而家嘅估值。

### 2.3 拖累估值嘅風險因素(你哋要留意,亦都已經部分避開咗)
<cite index="22-1">冇獨有數據:你嘅微調素材競爭對手一樣攞到;單一API依賴:你嘅利潤/
路線圖受制於單一模型供應商嘅下一次加價;毛利率薄:你將大部分營收直接交俾模型API,
睇落好似個轉售商,而唔係軟件公司。</cite>

你哋嘅實際情況:因為你哋堅持「傳統確定性編程做核心引擎」呢個決策,已經天然
避開咗第一同第三個風險——你哋唔係「轉售第三方API」,而係有自己一套獨立、可審計、
IP可保護嘅規則庫。呢個係你哋喺呢份研究入面,少數幾個已經做啱嘅結構性決定之一。

## Part 3:點賣——商業化路徑總覽(呼應之前商業模式文件)

### 3.1 授權/開源優化嘅收入轉換
<cite index="24-1">如果一個創辦人將公司20%嘅營收由服務轉做授權,佢哋唔止提升咗利潤率——
佢哋令間公司進入完全唔同嘅估值級距。</cite>

對你哋嘅意義:你哋之前文件20已經定咗「授權俾機械人硬件商(UBTech/AheadForm/
Realbotix)」嘅B2B路線——呢個發現進一步證實咗,授權/專利收入嘅商業模式,對估值嘅
提升幅度,大過純服務型收入。

### 3.2 IP審計嘅時機建議
<cite index="21-1">喺融資前6至12個月開始:做一次獨立IP審計(可提升估值倍數15-20%)、
就住製造最大競爭距離嘅創新申請專利、記錄你哋嘅專有數據資產、建立授權選擇性。</cite>

對你哋嘅意義:你哋而家(仲喺概念驗證階段)先開始整理呢啲文件,時機上其實
啱啱好——建議喺真正接觸投資者/客戶之前,已經將「邊啲係專利、邊啲係商業機密」
分清楚(呼應Part 1),唔好等到談判緊嗰刻先臨急抱佛腳。

## Part 4:實際建議行動清單

```
短期(接觸客戶/投資者之前):
- 揀2-3個「最難俾對手繞過」嘅技術點,搵專利律師評估可行性
  (建議候選:Layer架構嘅「生成/偵測分離」設計、Layer CA跨物種適配架構)
- 註冊「Amoji」商標(成本低、風險低、保護明確)
- 將所有數值表(肌肉幅度矩陣、情緒公式具體參數)標記做商業機密,
  唔好完整公開喺任何俾外部人睇嘅文件度(包括之前俾Claude Code嘅Complete
  Spec,如果將來要俾第三方睇,建議做一個刪減版本,唔洩露具體數值)
- 建立基本IP轉讓範本(如果日後有合作開發者/員工)

中期(有初步產品/首批用戶之後):
- 正式做一次IP審計(對估值有實際、可量化嘅提升)
- 視乎資源,考慮1-2個臨時專利申請(成本相對可控)

長期(準備融資/授權談判):
- 將授權收入模式(而唔止服務收入)做成主要商業論述,呼應估值倍數研究
```

## 最重要嘅提醒
以上所有數字都係「行業大概參考」,唔係你哋嘅實際估值——真正嘅估值需要專業
估值師,基於你哋實際嘅團隊、產品完成度、市場驗證做評估。專利可行性亦都必須由
執業專利律師做正式檢索同評估,先可以確定邊啲部分真係可以申請到專利。
