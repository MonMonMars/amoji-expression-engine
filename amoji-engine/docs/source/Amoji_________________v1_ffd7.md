# Amoji 系統規格 —— Part X:臉部肌肉編號目錄 + 情緒動作幅度表

## 設計原則(你嘅指示,正式記錄低)
**開心、關懷類情緒 → 動作幅度(perimeter)闊**;**指責、憤怒類情緒 → 動作幅度窄、克制**。
呢個唔係話憤怒嘅肌肉唔郁,而係刻意做成「收緊、控制住」嘅質感——研究上,呢種「隱忍/克制式
憤怒」往往比誇張外露嘅憤怒更加令人感受到壓迫感(對應之前文件17嘅「憤怒-隱忍型」備註),
亦都同你套系統嘅專業/克制人格(企業文件、醫療照護)一致。

⭐ **指責情緒嘅特殊組合**:M13(提口角肌,輕蔑單邊上提)同 M20(咬肌,緊咬)嘅幅度**相對
其他肌肉保持較高**——即係話「指責」唔係全面收窄,而係**選擇性收窄**:眉毛/額頭/鼻部呢啲
「外顯情緒強度」嘅肌肉全面壓低,但 M13(輕蔑嘴角)同 M20(緊咬牙關)呢兩條「傳達意圖」
嘅肌肉維持中高幅度——結果係一個表面克制、但眼神/嘴角依然傳達強烈負面意圖嘅表情,呢個
先係「指責」呢種情緒嘅心理質感:唔嘈吵,但銳利。

**設計解讀**:留意「憤怒」欄同「指責」欄嘅分別——憤怒本身已經跟返之前文件嘅數值(中高
幅度),但「指責」特登整體壓低過憤怒(對比 M1: 0.3 vs 0.15;M2: 0.7 vs 0.35),示範緊
「隱忍/控制式」嘅負面情緒質感,對應你要求嘅「blaming 幅度更窄」。

## Part 4:實作建議
每個情緒公式(文件4-6)嘅每個參數,而家可以加返一條「muscle perimeter cap」——即係
Layer 1 公式輸出嘅原始強度值,最終要 clamp 喺呢張表對應嘅 perimeter 上限之內,先至
輸出去 Layer 2 點位。呢個係一個額外嘅「風格化封頂層」,獨立於情緒公式本身,方便你日後
統一調整「呢個角色/人格,情緒表現要幾誇張定幾克制」,唔使逐條公式手改。

```javascript
function applyMusclePerimeter(rawValue, muscleId, emotionId) {
  const cap = MUSCLE_PERIMETER_TABLE[muscleId][emotionId];
  return clamp(rawValue, -cap, cap);
}
```
