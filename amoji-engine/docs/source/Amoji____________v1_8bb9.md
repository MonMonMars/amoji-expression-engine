## 總覽:20個Phase嘅依賴關係

```
Phase 0(基礎設施+合規骨架)
   ↓
Phase 1(核心臉部)→ Phase 2(肌肉/口型)→ Phase 3(時間軸)
   ↓
Phase 4(劇本/複合情緒/心情) → Phase 5(延遲橋接) → Phase 6(人格,掛鈎合規)
   ↓
Phase 7(眼球) → Phase 8(共同發音,選用)
   ↓
Phase 9(頸肩呼吸) → Phase 10(手勢) → Phase 11(待機) → Phase 12(步態,選用)
   ↓
Phase 13(笑嘅子狀態) → Phase 14(全身點位,3D專屬) → Phase 15(Easter Egg,選用)
   ↓
Phase 16(輸出相容) → Phase 17(恐怖谷驗證) → Phase 18(合規驗證)
   ↓
Phase 19(本地化,視市場而定) → Phase 20(正式產品化)
```

建議 MVP 範圍:Phase 0-6(核心表情引擎 + 人格 + 合規骨架)已經足夠做第一個可以
展示嘅版本;Phase 7 起可以按產品線需要(2D/3D、動畫師工具/機械人)彈性排序。
