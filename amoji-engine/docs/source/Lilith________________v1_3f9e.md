## Part 1:頸肩肌肉解剖

### 1.1 斜方肌(Trapezius)——「肩上重擔」嘅字面解剖學根據
<cite index="47-1">斜方肌係上背嘅三角形肌肉,負責穩定同郁動肩胛骨,令你可以聳肩。</cite>但長期繃緊有明確後果:
<cite index="52-1">當頭部前傾(forward head posture),上斜方肌就要長期過度工作、永遠都放鬆唔到,先可以阻止個頭進一步向前墜。長時間如此,呢條肌肉會變得過度勞損、繃緊、疼痛。</cite>

**對你套系統嘅意義**:「聳肩」(shoulderHeight 參數)唔止係一個孤立嘅姿勢選擇,佢同「頭部前傾/
低垂」(headTiltVertical)有解剖學上嘅連動關係——低頭嗰陣,斜方肌會自動代償性繃緊,即係話
呢兩個參數應該有一定嘅連動邏輯,而唔係完全獨立。

### 1.2 提肩胛肌(Levator Scapulae)——「打量、戒備」動作嘅肌肉
<cite index="56-1">呢條肌肉起源於頸椎 C1 至 C4,插入肩胛骨上角,負責:向同側傾側個頭、輕微轉動頸部、穩定手臂
過頭動作嗰陣嘅肩膊。呢條肌肉喺你「望過肩膊」、單側背重物、或者長期姿勢不良嗰陣特別活躍。</cite>

**對你套系統嘅意義**:「側望/望過肩膊」呢類動作(對應之前懷疑情緒嘅側目)喺解剖學上會伴隨
提肩胛肌嘅輕微活躍——如果要加身體層嘅細節,呢條肌肉嘅張力可以對應「戒備/懷疑」呢類情緒。

### 1.3 胸鎖乳突肌(SCM)——⭐ 雙重身份肌肉(關鍵發現)
<cite index="47-1">SCM 由鎖骨伸展到顳顎關節,負責轉頭、側傾、前屈頭部,喺運動、姿勢不良嗰陣容易繃緊酸痛。</cite>
<cite index="49-1">呢條肌肉經常涉及壓力反應。</cite>

### 1.4 斜角肌(Scalenes)——同樣係雙重身份
<cite index="49-1">呢組頸側嘅三塊肌肉負責固定頸椎,同時參與呼吸。</cite>

## Part 2:呼吸肌肉解剖

### 2.1 橫膈膜(Diaphragm)——主要吸氣肌肉
<cite index="61-1">橫膈膜係主要吸氣肌肉,吸氣時收縮並向下移動,增加胸腔垂直徑,令肺部擴張、空氣被吸入。</cite>

### 2.2 肋間肌(Intercostals)——平靜呼吸嘅主力
<cite index="65-1">外肋間肌負責平靜吸氣,令肋骨向上向外移動,佔胸腔容積增加嘅大約 25%。</cite><cite index="57-1">內肋間肌就喺用力呼氣嗰陣,同腹直肌一齊參與。</cite>

### 2.3 ⭐⭐ 呼吸輔助肌肉(Accessory Muscles)——同頸部肌肉係同一班「演員」
呢個係整份文件最關鍵嘅發現:<cite index="57-1">當需要更深、更用力嘅呼吸(例如運動嗰陣),輔助肌肉會
介入,進一步擴大胸腔——呢啲肌肉正正就係:胸鎖乳突肌、斜角肌、前鋸肌。</cite><cite index="65-1">用力/急促呼吸期間會徵召嘅額外「輔助」肌肉包括胸鎖乳突肌同斜角肌。</cite>

## Part 3:⭐ 核心洞見——頸緊同急促呼吸唔係「兩件事啱啱同時發生」,而係「同一組肌肉」

**呢個發現直接影響你套系統嘅參數設計**:胸鎖乳突肌(SCM)同斜角肌,同時擔任兩個角色——
(1) 頭頸嘅轉動/側傾/繃緊肌肉,(2) 用力/急促呼吸嘅輔助呼吸肌肉。

即係話,當一個角色處於恐懼/憤怒/焦慮呢類高喚醒負面情緒,你之前分開設計嘅兩個參數——
`shoulderHeight`(頸肩繃緊)同 `breathingRate/breathingDepth`(急促淺呼吸)——**喺真實人體
入面根本係同一組肌肉(SCM + 斜角肌)被同時徵召嘅結果**,唔係兩個獨立巧合、剛好一齊出現嘅
現象。

### 3.1 建議修正:加一個「統攝參數」

```
accessoryMuscleActivation (0–1)
  → 同時驅動:
     ├─ neckTension(頸部可見繃緊、頸側肌肉輪廓明顯)
     ├─ shoulderHeight 嘅提升(SCM/斜角肌牽動肩頸)
     └─ breathingMode 切換去「輔助肌驅動」模式(淺、急、可見頸部用力)
```

**同「平靜呼吸」模式對比**:
| 呼吸模式 | 主導肌肉 | 頸肩表現 | 呼吸特徵 |
|---|---|---|---|
| 平靜(橫膈膜+外肋間肌主導) | 橫膈膜、外肋間肌 | 頸肩放鬆,冇可見肌肉張力 | 慢、深、規律,胸腹起伏均勻 |
| 用力/緊張(輔助肌介入) | +SCM、斜角肌、前鋸肌 | **頸側可見繃緊、肩膊隨每次吸氣微微提升** | 快、淺、可能不規則 |

**呢個對你之前情緒對照表(文件17 Part 4)嘅修正**:恐懼、憤怒、焦慮呢類情緒嘅
`shoulderHeight` 同 `breathingRate/Depth`,應該由**同一個 `accessoryMuscleActivation` 數值
驅動**,而唔係分開兩條數值曲線手動對齊——呢個唔止簡化咗參數(少咗一組要逐個情緒手調嘅數字),
仲令個系統更加解剖學準確:**你會見到用力呼吸嗰陣,肩頸會跟住吸氣節奏微微起伏**,呢個細節係
純粹「肩膊固定聳起 + 獨立嘅呼吸動畫」做唔到嘅真實感。

### 3.2 修正後嘅 Layer B 參數表

| 參數 | 說明 |
|---|---|
| `accessoryMuscleActivation` | 0=完全放鬆(橫膈膜/肋間肌主導)、1=完全輔助肌驅動(SCM/斜角肌主導) |
| ↳ 衍生 `neckVisibleTension` | = accessoryMuscleActivation(頸側肌肉輪廓可見度) |
| ↳ 衍生 `shoulderMicroLift` | = accessoryMuscleActivation × breathingRate(肩膊隨每次吸氣嘅微幅提升,而唔止靜態聳肩) |
| ↳ 衍生 `breathingMode` | accessoryMuscleActivation > 0.5 時切換做「淺急模式」 |
| `headTiltVertical/Lateral` | 沿用文件17 定義,獨立於呼吸系統 |
| `chestExpansion` | 沿用文件17,但注意橫膈膜/肋間肌主導時,胸腹起伏應該更均勻平順;輔助肌主導時,起伏集中喺上胸,更急促 |
