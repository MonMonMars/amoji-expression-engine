## 五類手勢分類法 + 覆蓋/組合架構

## Part 1:Ekman & Friesen 五類手勢分類法——你問嘅「覆蓋定組合」嘅現成答案

呢個係非語言溝通研究入面最重要嘅分類系統,1969 年提出,沿用至今。<cite index="68-1">Ekman 同 Friesen
劃分咗五類非語言行為:情感展示(Affect Displays)、調節器(Regulators)、適應器(Adaptors)、
說明性動作(Illustrators)、同符號動作(Emblems)。</cite>

### 1.1 五個類別逐一解釋

**符號動作(Emblems)**——<cite index="75-1">獨立於語言,有自己精確嘅意思,唔需要靠講嘢先睇得明(例如
手掩耳朵表示「聽唔到」)。</cite>呢類動作係**刻意、有意識**做出嚟嘅。

**說明性動作(Illustrators)**——<cite index="75-1">需要靠語言先理解意思嘅手勢,即係伴隨/說明緊講緊嘅嘢。</cite>
細分類別包括:<cite index="68-1">節拍動作(強調用)、圖像動作(模仿所指物件形狀)、動態動作(模仿身體動作本身)、
意念動作(描繪思路走向)、指示動作(指嘢)、空間動作(描繪空間關係)。</cite>**重要發現**:
<cite index="75-1">說明性動作使用頻率增加,代表對話題有正面投入;使用頻率減少,就可能代表悶、攰,或者
講大話/緊張(講大話/緊張嗰陣說明性動作會減少)。呢個對比抑鬱症患者康復前後嘅研究都證實咗:
情緒改善咗之後,說明性動作嘅使用反而會增加。</cite>

**調節器(Regulators)**——<cite index="68-1">維持同組織對話雙方之間嘅互動流程</cite>,例如<cite index="70-1">
點頭表示認同、喺空中畫圈表示「快啲講」、伸出手掌表示想暫停。</cite>

**適應器/操縱器(Adaptors/Manipulators)**——<cite index="75-1">Ekman 後來將呢個詞改做「操縱器」,更準確
噉描述呢類行為:身體或者臉嘅一部分操縱緊另一部分(例如撫摸面側、將頭髮繞喺手指度)。</cite>
<cite index="68-1">呢類動作幫手管理內在嘅緊張或者壓力狀態</cite>,再細分:<cite index="68-1">物件適應器(擺弄一件
物件,例如筆)、人際適應器(用喺人際接觸,例如觸摸他人)、自我適應器(咬指甲、揉眼、抓癢)。</cite>
**重要特性**:<cite index="75-1">操縱器有傳染性——當我哋見到人做緊呢類動作,我哋會傾向模仿。</cite>

**情感展示(Affect Displays)**——<cite index="72-1">帶有情緒意義嘅身體或臉部非語言展示。我哋嘅步態(彈跳
代表開心,或者垂頭喪氣拖著腳步代表抑鬱)、我哋嘅臉部動作,都傳達緊我哋嘅感受狀態。</cite>

### 1.2 呢個分類法點樣解決你嘅「覆蓋/組合」問題

呢五類唔止係分類,佢哋本身已經隱含咗一個優先次序/來源邏輯,同你之前口型系統嘅「Layer 0 劇本
主導 vs 情緒自由發揮」邏輯高度呼應:

| 類別 | 觸發來源 | 對應你套系統 |
|---|---|---|
| Emblems | AI 劇本明確指令(「打個 OK 手勢」) | Layer 0(劇本),類似口型系統嘅 MBP——完全鎖定 |
| Illustrators | 伴隨語音同步(講嘢節奏、強調重點) | Layer V(口型/語音同步),同 viseme 系統屬於同一類「言語驅動」行為 |
| Regulators | 對話輪流管理(等/認同/暫停) | Layer T(延遲橋接)——你已經有嘅「填充語+動作」概念可以延伸做手勢版 |
| Affect Displays | 情緒強度值直接驅動 | Layer 1(情緒)+ Layer B(身體姿態)——已經喺文件17做咗軀幹版本,而家加手臂版 |
| Adaptors | 心情(Mood)/焦慮程度驅動,自主觸發,唔靠劇本 | Layer D(演員自由度引擎)——同「主動即興」屬於同一機制,填補劇本冇覆蓋嘅空隙 |

## Part 2:各情緒嘅具體手臂/手部動作研究

### 2.1 六大基本情緒嘅身體語言(整合兩份獨立研究,互相印證)

<cite index="33-1">開心:主要透過臉部表現,偶爾有跳躍動作及/或張開舉起雙手。傷心:雙手掩面哭泣、靜止不動。
驚訝:手部動作冇特定模式,可正可負。恐懼:雙臂在胸前交叉。厭惡:身體遠離動作或者用手推開。
憤怒:握拳、雙臂交叉、肩膊繃緊方正。</cite>

<cite index="35-1">恐懼:手或手臂握緊、手肘向內收、動作彈跳不定、雙腿纏繞物件、屏住呼吸。憤怒:身體展開、手叉腰、
握拳、手掌向下、用右手或左手指嘢、手指或手不停震。傷心:身體垂下、身體縮小、彎腰駝背、雙手掩面、
自我觸摸(難以置信嘅動作)、身體部位被遮蓋或者雙臂環抱身體/肩膊。</cite>

### 2.2 每種情緒建議嘅 Adaptor(自我操縱動作)——呢啲最啱做「劇本冇講、演員自己加」嗰種
- **緊張/尷尬**:撫摸頸背、擰手指、玩弄衣角或者頭髮
- **思考**:掂下巴、輕敲手指
- **懷疑**:抱手臂(輕度,非防禦性咁強)、單手撐下巴
- **憤怒(隱忍)**:握緊拳頭但唔完全揮動、手指關節輕微反覆屈曲

### 2.3 高度表達性手勢群集——同「喚醒度」有關
研究發現一個特定嘅手勢組合模式:<cite index="74-1">一個高度表達性嘅手勢群集(雙臂向前伸展、使用說明性
手勢、雙手開合、肩膊上下郁動),特別對應高喚醒度嘅情緒狀態。</cite>——呢個直接呼應你之前 Layer B
嘅「呼吸/肩膊」發現,證明手臂手勢同軀幹/呼吸系統喺高喚醒情緒下係聯動嘅。

## Part 3:覆蓋/組合架構(仿照口型系統嘅 LOCKED/CLAMPED/OPEN)

### 3.1 優先次序(數字越細,優先權越高,可以覆蓋低優先級)

```
1. Emblem(劇本明確指令)       → LOCKED:完全鎖定手勢形狀,情緒/其他層完全唔可以碰
2. Illustrator/Regulator(語音同步) → CLAMPED:基礎節奏由語音/對話流程決定,情緒可以調整
                                        「力度/幅度」但唔可以改變手勢嘅基本形狀語意
3. Affect Display(情緒姿態)   → OPEN(當上面兩層都冇觸發時全權主導)
4. Adaptor(自我操縱)          → 只喺 1-3 都冇填滿嘅「空隙時間」自主觸發,強度由 Mood/焦慮值決定
```

### 3.2 具體規則範例
- 如果 AI 劇本要求「打招呼揮手」(Emblem)→ 手部動作 100% 由呢個手勢主導,情緒最多只可以
  微調「揮手嘅力度/速度」(例如開心揮手快啲、傷心揮手慢啲——呢個微調幅度好似口型嘅 corner
  參數噉,有限度開放)
- 如果角色講緊嘢冇特定 Emblem,但語音有重點——Illustrator(節拍手勢)自動生成,情緒決定
  手勢嘅「銳利度」(憤怒嘅節拍手勢會更快更硬,開心會更鬆軟圓潤)
- 如果冇講嘢、冇特定手勢指令,純粹企定定聽人講——Affect Display 接管(例如恐懼嗰陣雙臂
  交叉抱身)
- 如果角色長時間冇任何手部動作指令(例如安靜聆聽超過幾秒),Adaptor 開始自主觸發——
  根據 Mood(例如「尷尬底色」)觸發對應嘅自我觸摸動作(玩頭髮、摸頸背)

### 3.3 同 Layer D(演員自由度引擎)嘅關係
Adaptor 呢一層本質上就係你之前 Layer D「主動即興」機制嘅手部版本——建議實作時直接掛喺
Layer D 之下,共用番嗰套「冇劇本覆蓋嘅空隙自動填補」邏輯,唔使重新設計一套獨立系統。

## Part 4:整合返 Layer 架構

```
Layer G · 手勢層(新增)
├─ Emblem Resolver    ← 讀取 Layer 0 劇本明確指令,LOCKED 狀態
├─ Illustrator Sync    ← 讀取 Layer V 語音節奏,CLAMPED 狀態,情緒調整力度/銳利度
├─ Regulator Trigger   ← 讀取 Layer T 延遲橋接狀態(等待/確認手勢)
├─ Affect Display      ← 讀取 Layer 1 情緒值,OPEN 狀態全權主導(當以上都未觸發)
└─ Adaptor Engine      ← 讀取 Layer -1 Mood + Layer D 空隙偵測,自主觸發自我操縱動作
```
