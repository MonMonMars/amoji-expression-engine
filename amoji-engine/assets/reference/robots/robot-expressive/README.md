# RobotExpressive

`RobotExpressive.glb` from [three.js examples](https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive).

- Model by [Tomás Laulhé / Quaternius](https://quaternius.com/) — **CC0 1.0**
- Morph targets (Angry, Surprised, Sad) + animation clips by Don McCurdy / three.js pipeline

Face Live drives morphs via `robotEmotionDrive.js` and plays embedded Idle/Walk.
