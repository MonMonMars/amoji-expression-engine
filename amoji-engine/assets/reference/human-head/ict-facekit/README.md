# ICT Face Model Light (subset)

From [USC-ICT/ICT-FaceKit](https://github.com/USC-ICT/ICT-FaceKit) — **MIT**.

Vendored here (small subset only):

- `generic_neutral_mesh.obj` — base topology
- `eyeBlink_L.obj`, `jawOpen.obj` — sample expression targets (ARKit-style names)
- `ICTFaceModelMaterial.mtl`, `LICENSE`, `CREDITS.md`

Full Light model (100 PCA identity OBJs + ~53 expressions) lives on GitHub under `FaceXModel/`.  
The **Full** ICT Face Model (albedo PCA, FBX rig) is a separate USC commercial license — not this MIT Light kit.
