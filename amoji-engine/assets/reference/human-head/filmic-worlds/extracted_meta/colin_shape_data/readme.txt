Included in this package is the processed data for the scan shoot. The data is licensed under CC0, as described in cc0_license.txt.

colin_base_shapes.fbx:
These shapes were made from the original FaceCap file (which use the ARKit). The topology was transferred, and then the offsets of the original file
were directly applied to the scanned neutral pose. So the shape offsets match the original ArKit data.

colin_proc_rig.fbx:
These are the cleaned, processed shapes from the original scanning shoot. Additionally, the json folder stores the ArKit weights for each pose.

colin_dst_rig.fbx:
The final rig, solved to the ARKit shapes.

colin_dst_calisthenics.fbx:
The final rig (same poses as colin_dst_rig.fbx) with an animation to scroll through to see each pose.

colin_anim_dst_facecap.fbx
The final rig (same poses as colin_dst_rig.fbx) with sample FaceCap animation weights.

colin_dst_rig_shape_fit.fbx
The final rig (same poses as colin_dst_rig.fbx), but each frame is a pose with the ArKit weights from the json directory.

Eyes:
The eyes were treated as two spheres at the following positon and size. Add two spheres if you wish to the rig.

L Eye Position: ( 3.316,10.056,6.185)
R Eye Position: (-3.372,10.236,6.118)
Eye Size: 1.546
