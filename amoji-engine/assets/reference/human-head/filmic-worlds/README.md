# Filmic Worlds — ARKit face solve dataset

From [John Hable / Filmic Worlds](https://filmicworlds.com/blog/solving-face-scans-for-arkit/) — **CC0**.

- `colin_shape_data.zip` — FBX heads/rigs + `json/pose_*.json` (expression → ARKit 52 weights)
- `extracted_meta/` — license + JSON pose maps (FBX stay in the zip)

Use for blendshape solve research and ARKit weight interop — not as the Amoji brand face.
